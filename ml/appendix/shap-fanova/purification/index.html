    3. Purification — 트리 모형의 사후 정제¶

    왜 Purification이 필요한가¶

    2절에서 Integrate-to-Zero 조건이 (주어진 측도 위에서) fANOVA 분해를 유일하게 결정하고, Zero Means·Orthogonality·Variance Decomposition이 그 결과로 따라온다는 것을 확인했다. 문제는, XGBoost 같은 트리 기반 모형이 학습 과정에서 이 제약을 전혀 고려하지 않는다는 것이다. 트리는 단지 예측 오차를 줄이는 방향으로 분할할 뿐이고, "이 효과가 main에 담겨야 하는가, interaction에 담겨야 하는가"를 구분하지 않는다. (EBM은 학습 파이프라인에서 분리를 시도하지만, 그것만으로는 완전하지 않다 — 뒤에서 자세히 다룬다.)

    그 결과, 학습된 shape function에서 main effect와 교호작용이 뒤섞인다. 본래 \(f_1(X_1)\)에 있어야 할 효과가 \(f_{12}(X_1, X_2)\)에 누출되거나, 반대로 교호작용의 일부가 main effect에 흡수된다.

    1절에서 확인한 것처럼, 이 누출은 예측값을 전혀 바꾸지 않는다. 예측 성능은 동일하지만 해석이 완전히 달라진다. 이것을 사후적으로(post-hoc) 바로잡아서 fANOVA의 Integrate-to-Zero 조건을 만족시키는 것이 purification(정제)이다.

    이 절에서는 purification이 구체적으로 무엇을 하는지 숫자 예시로 먼저 확인한 뒤, 그것을 일반화한 Mass-Moving 알고리즘을 소개한다.

    핵심 아이디어 — 숫자로 먼저 이해하기¶

    알고리즘을 보기 전에, 신용평가 맥락의 가상 숫자 예시로 직관을 잡자. 결론부터 말하면, main effect가 전부 0이고 교호작용이 지배적인 것처럼 보이는 모형이, purification 후에는 main effect가 핵심이고 교호작용은 미미한 것으로 바뀐다.

    설정¶

    DTI(총부채상환비율)와 소득, 두 변수가 각각 2구간(Low, High)인 depth-2 XGBoost 모형이다. 모형 출력은 불량(Bad) 로짓에 더해지는 값이므로 값이 클수록 위험하다. 네 구간 조합의 데이터 비중은 모두 같다고(각 25%) 가정한다. 학습된 결과가 다음과 같다고 하자 (설명을 위한 가상 수치):

    component 값
    \(f_0\) (intercept) 0
    \(f_{\text{DTI}}(\text{Low})\) 0
    \(f_{\text{DTI}}(\text{High})\) 0
    \(f_{\text{소득}}(\text{Low})\) 0
    \(f_{\text{소득}}(\text{High})\) 0
    \(f_{12}\) 교호작용 소득=Low 소득=High
    DTI=Low +0.1 -0.7
    DTI=High +0.5 +0.1

    main effect가 전부 0이고, 모든 효과가 교호작용에 담겨 있다. 이 모형의 해석은 "DTI도 소득도 개별 효과는 없고, 오직 두 변수의 조합만 중요하다"가 된다.

    정말 그런가? 교호작용 테이블을 자세히 보면, 뭔가 이상하다. 소득=Low인 열의 값들(+0.1, +0.5)이 소득=High인 열의 값들(-0.7, +0.1)보다 전반적으로 높다. 이것은 "소득이 낮으면 위험하다"는 패턴인데, 이 패턴은 소득 구간에만 의존하고 DTI와 무관하다. 즉, 소득의 main effect가 교호작용에 누출되어 있다는 신호다. 2절에서 다룬 Integrate-to-Zero 조건으로 말하면, 소득 방향의 열 평균이 0이 아니라는 것이다.

    Purification 실행¶

    Purification은 이 누출을 찾아서 원래 있어야 할 곳으로 되돌린다. 2절의 Integrate-to-Zero 조건이 "교호작용 테이블의 모든 행/열 평균이 0이어야 한다"는 것이었으므로, 행/열 평균이 0이 될 때까지 평균값을 main effect로 옮기면 된다.

    1단계 — 소득의 누출을 찾아서 되돌린다

    교호작용 테이블에서 각 소득 구간별로, DTI 방향의 가중평균을 구한다 (균등 가중):

    \[ \text{소득=Low 열의 평균}: \frac{0.1 + 0.5}{2} = +0.3 \]
    \[ \text{소득=High 열의 평균}: \frac{-0.7 + 0.1}{2} = -0.3 \]

    이 평균값(+0.3, -0.3)은 소득 구간에만 의존하고 DTI와 무관하다. 따라서 교호작용이 아니라 소득의 main effect다. 이것을 교호작용에서 빼고, main effect로 옮긴다:

    \(f_{\text{소득}}\) 업데이트:

    이전 이동량 이후
    소득=Low 0 +0.3 +0.3
    소득=High 0 -0.3 -0.3

    \(f_{12}\) 업데이트 (각 열에서 해당 평균을 뺀다):

    \(f_{12}\) 소득=Low 소득=High
    DTI=Low \(0.1 - 0.3 = \mathbf{-0.2}\) \(-0.7 - (-0.3) = \mathbf{-0.4}\)
    DTI=High \(0.5 - 0.3 = \mathbf{+0.2}\) \(0.1 - (-0.3) = \mathbf{+0.4}\)

    검산 — 소득 방향의 누출이 제거되었는지 확인:

    • 소득=Low 열의 평균: \((-0.2 + 0.2)/2 = \mathbf{0}\) ✓
    • 소득=High 열의 평균: \((-0.4 + 0.4)/2 = \mathbf{0}\) ✓

    소득 방향은 깨끗해졌다. 그런데 아직 DTI 방향(행 평균)이 남아 있다.

    2단계 — DTI의 누출을 찾아서 되돌린다

    이번에는 각 DTI 구간별로, 소득 방향의 가중평균을 구한다:

    \[ \text{DTI=Low 행의 평균}: \frac{-0.2 + (-0.4)}{2} = -0.3 \]
    \[ \text{DTI=High 행의 평균}: \frac{0.2 + 0.4}{2} = +0.3 \]

    이것은 DTI 구간에만 의존하는 효과 → DTI의 main effect다. 교호작용에서 빼고, main effect로 옮긴다:

    \(f_{\text{DTI}}\) 업데이트:

    이전 이동량 이후
    DTI=Low 0 -0.3 -0.3
    DTI=High 0 +0.3 +0.3

    \(f_{12}\) 업데이트 (각 행에서 해당 평균을 뺀다):

    \(f_{12}\) 소득=Low 소득=High
    DTI=Low \(-0.2 - (-0.3) = \mathbf{+0.1}\) \(-0.4 - (-0.3) = \mathbf{-0.1}\)
    DTI=High \(0.2 - 0.3 = \mathbf{-0.1}\) \(0.4 - 0.3 = \mathbf{+0.1}\)

    검산 — 모든 행/열 평균이 0인지 확인:

    • DTI=Low 행의 평균: \((0.1 + (-0.1))/2 = 0\) ✓
    • DTI=High 행의 평균: \((-0.1 + 0.1)/2 = 0\) ✓
    • 소득=Low 열의 평균: \((0.1 + (-0.1))/2 = 0\) ✓
    • 소득=High 열의 평균: \((-0.1 + 0.1)/2 = 0\) ✓

    모든 행/열 평균이 0이다. Integrate-to-Zero 조건을 만족하므로, 수렴 완료.

    결과 비교¶

    Purification 전:

    component 값 해석
    \(f_{\text{DTI}}\) Low=0, High=0 "DTI는 개별 효과 없음"
    \(f_{\text{소득}}\) Low=0, High=0 "소득도 개별 효과 없음"
    \(f_{12}\) -0.7 ~ +0.5 (넓은 범위) "교호작용이 지배적"

    Purification 후:

    component 값 해석
    \(f_{\text{DTI}}\) Low=-0.3, High=+0.3 "DTI 높으면 위험 ↑"
    \(f_{\text{소득}}\) Low=+0.3, High=-0.3 "소득 높으면 위험 ↓"
    \(f_{12}\) ±0.1 (작은 범위) "순수 교호작용은 미미"

    같은 모형, 같은 예측값인데 해석이 완전히 달라졌다. 교호작용이 지배적이었던 모형이 실은 main effect가 핵심이었고, 교호작용은 미미했다. 이것이 purification의 효과다.

    예측값이 보존되는지 검산¶

    Purification은 효과의 귀속(attribution)만 바꾸고, 예측은 건드리지 않는다. 4개 입력 모두에서 확인하자:

    입력 Purification 전 Purification 후
    DTI=Low, 소득=Low \(0 + 0 + 0 + 0.1 = \mathbf{0.1}\) \(0 + (-0.3) + 0.3 + 0.1 = \mathbf{0.1}\) ✓
    DTI=Low, 소득=High \(0 + 0 + 0 + (-0.7) = \mathbf{-0.7}\) \(0 + (-0.3) + (-0.3) + (-0.1) = \mathbf{-0.7}\) ✓
    DTI=High, 소득=Low \(0 + 0 + 0 + 0.5 = \mathbf{0.5}\) \(0 + 0.3 + 0.3 + (-0.1) = \mathbf{0.5}\) ✓
    DTI=High, 소득=High \(0 + 0 + 0 + 0.1 = \mathbf{0.1}\) \(0 + 0.3 + (-0.3) + 0.1 = \mathbf{0.1}\) ✓

    4개 입력 모두 예측값이 정확히 일치한다.

    Mass-Moving 알고리즘 (Lengerich et al., 2020)¶

    위 예시에서 한 것을 일반화한 것이 Mass-Moving 알고리즘이다. piecewise-constant 함수(트리 모형의 출력)에 대해 적용 가능하다.

    사전 단계 — 트리 앙상블을 효과 텐서로 바꾸기¶

    purification은 "교호작용 테이블"을 입력으로 받는다. 트리 앙상블에서 이 테이블을 만드는 절차는 다음과 같다 (Lengerich et al., 2020, 6절).

    1. 각 변수의 구간 정하기 — 앙상블 전체에서 그 변수에 쓰인 분할 경계(threshold)를 모두 모으면, 변수마다 구간(bin)이 정해진다. 모든 트리의 출력은 이 구간들의 조합 위에서 상수다.
    2. leaf를 변수 집합별로 모으기 — 각 leaf에 이르는 경로에 등장한 변수 집합 \(u\)를 확인한다. depth-2 트리라면 \(u\)는 변수 1개 또는 2개다.
    3. 텐서에 더하기 — leaf 값을 해당 변수 집합의 텐서 \(T_u\)(변수 \(u\)의 구간 조합마다 칸이 하나씩 있는 표)의 해당 칸들에 더한다. 모든 트리에 대해 반복하면, 모형 전체가 \(\sum_u T_u\)로 표현된다.
    4. 가중치 준비 — 각 칸에 데이터 비중(또는 다른 선택한 분포의 확률)을 가중치로 붙인다. 어떤 가중치를 쓸지는 아래 "어떤 가중(측도)을 쓸 것인가"에서 다룬다.

    이렇게 만든 \(T_u\)는 1절에서 본 대로 트리의 분할 순서에 따라 정해진 "임의의 분해" 중 하나다. purification은 이것을 fANOVA 정준형으로 옮긴다.

    단일 텐서 정제 (Purify-Matrix)¶

    위 예시의 1단계와 2단계를 다시 보면, 패턴이 보인다: (1) 한 방향으로 가중평균을 구하고, (2) 그 평균을 교호작용에서 빼고, (3) main effect에 더한다. 이것을 모든 변수에 대해 반복하면 된다. 하나의 교호작용 텐서 \(T_u\)를 정제하는 절차를 일반화하면:

    입력: 교호작용 텐서 T_u, 가중치 w

반복 (모든 slice 가중평균이 0이 될 때까지):

    for each 변수 i ∈ u:
        for each (나머지 변수 고정값) x_{u\i}:

            ① m ← 변수 i 방향으로 slice 가중평균 계산
            ② T_u 에서 m을 뺀다      ← 고차항에서 빼기
            ③ T_{u\i} 에 m을 더한다   ← 저차항에 더하기

    위 예시에서 ①②③이 정확히 어떻게 대응되는지 되짚어보자:

    단계 알고리즘 예시에서 한 것
    ① slice 가중평균 계산 "소득=Low 열의 DTI 방향 평균 = +0.3"
    ② 고차항에서 빼기 "소득=Low 열의 모든 값에서 0.3을 뺀다"
    ③ 저차항에 더하기 "\(f_{\text{소득}}(\text{Low})\)에 0.3을 더한다"

    전체 모형 정제 (Purify)¶

    실제 모형에는 2차뿐 아니라 3차 이상의 교호작용도 있을 수 있다(depth-3 이상의 트리). 이때는 가장 고차부터 한 단계씩 내려온다. Purify-Matrix는 \(T_u\)의 질량을 바로 아래 차수인 \(T_{u \setminus i}\)로만 옮기므로, 3차의 질량은 2차를 거쳐 main effect로, 다시 intercept로 흘러간다:

    Purify (전체 모형):
    3차 interaction → 2차 interaction으로 mass 이동
    2차 interaction → main effect로 mass 이동
    main effect → intercept(f₀)로 mass 이동

    각 단계에서 "이 텐서에 담긴 효과 중, 한 변수 적은 집합으로 설명 가능한 부분"을 아래로 내려보낸다. 최종적으로 각 component에는 해당 변수 조합에서만 나타나는 순수한 효과만 남는다.

    수렴 보장¶

    위 예시에서는 2단계(소득 → DTI 순으로 한 번씩)만에 모든 행/열 평균이 0이 되었다. 항상 이렇게 빨리 끝나는 것인가?

    한 번에 끝나는 경우 — 원논문 Theorem 1과 독립 가중¶

    Lengerich et al. (2020, 5.1절)의 Theorem 1은 2차원 텐서 \(T_{a,b}\)에서 가중치가 한 축 방향으로 같으면(\(w_{i,j} = w_{i,j'}\)) 행·열을 한 번씩 정리하는 것으로 수렴한다고 말한다. 모든 칸의 가중치가 같은 균등 가중이 대표적인 경우다.

    같은 결론은 가중치가 두 변수의 주변 비중의 곱(\(w_{i,j} = p_i\, q_j\), 즉 두 변수가 독립인 product measure)일 때도 성립한다. 행을 정리한 뒤 열을 정리해도 각 행의 가중평균이 다시 깨지지 않기 때문이다. 위 DTI/소득 예시는 네 칸이 모두 25%인 균등 가중이므로, 변수 2개를 한 바퀴 돌면 끝났다.

    상관이 있으면 반복이 필요하다 — 원논문 Theorem 2와 수렴 속도¶

    실제 데이터에서는 두 변수가 상관되어 있어, 칸별 비중이 주변 비중의 곱과 다르다. 예를 들어 DTI가 높은 차주가 소득도 낮은 쪽에 몰려 있을 수 있다. 이 경우 한 번의 순회로는 행/열 평균이 정확히 0이 되지 않는다 — 한 방향을 정리하면 다른 방향이 살짝 틀어지기 때문이다. 그래도 정리할 때마다 남은 질량은 기하급수적으로 줄어든다.

    원논문의 Theorem 2는 잔여 질량 \(M^t\)가 \(\varepsilon\) 이하가 되는 반복 횟수를 \(\log_2(M^0/\varepsilon)\)로 제시하는데, 이는 매 단계 질량이 절반 이하로 준다는 뜻이다. 그러나 이 속도는 두 변수의 상관 강도에 따라 달라지며, 상관이 강하면 그보다 느릴 수 있다. 아래 펼침 예시처럼 두 이진 변수가 대칭으로 상관된 2×2 가중에서는, 행 또는 열을 한 번 정리할 때마다 잔여 평균이 정확히 상관계수 \(\rho\)배로 줄어든다. 직접 계산한 결과는 다음과 같다:

    두 변수의 상관 \(\rho\) 한 단계(행 또는 열 정리)당 축소율 잔여를 처음의 \(10^{-6}\)로 줄이는 데 필요한 단계 수
    0.2 ×0.2 약 9
    0.4 ×0.4 약 15
    0.6 ×0.6 약 27
    0.8 ×0.8 약 62
    0.96 ×0.96 약 338

    따라서 "몇 번 반복하면 충분하다"는 고정된 숫자 대신, 잔여 slice 평균이 허용오차 이하가 될 때까지 반복하는 종료 조건을 쓰는 것이 안전하다. 원논문의 실험(5.3절)에서도 대부분의 질량은 첫 반복에서 이동했지만, 신용정보 변수처럼 강하게 상관된 변수 쌍(예: 업권별 대출 건수와 전체 대출 건수)에서는 수렴이 눈에 띄게 느려질 수 있다.

    비균등 가중에서의 수렴 과정 — 2×2 예시 (클릭하여 펼치기)

    본문의 DTI/소득 예시는 균등 가중이라 2단계만에 수렴했다. 비균등 가중(데이터가 특정 조합에 몰린 경우)에서는 어떻게 반복 수렴하는지, 스텝별로 추적하자.

    설정¶

    Interaction tensor (purify 대상 — 효과 크기):

    \[ T_{12} = \begin{pmatrix} 6 & 0 \\ 0 & 4 \end{pmatrix} \]

    Cell weight (데이터 비율 — 대각선에 몰린 비균등 가중):

    \[ w = \begin{pmatrix} 0.3 & 0.2 \\ 0.2 & 0.3 \end{pmatrix} \]

    100명 기준이면: \((x_1\!=\!0, x_2\!=\!0)\)에 30명, \((0,1)\)에 20명, \((1,0)\)에 20명, \((1,1)\)에 30명. 두 변수의 주변 비중은 모두 50:50이지만, 같은 값끼리 더 자주 나타나므로 양의 상관관계다. 상관계수는 \(\rho = (0.3 - 0.5 \times 0.5)/(0.5 \times 0.5) = 0.2\)이다.

    Main effects (초기): \(f_1 = [0,\; 0]\), \(f_2 = [0,\; 0]\)

    가중이 균등하거나 두 변수가 독립이면 행 centering 후 열 centering을 해도 행의 zero-mean이 깨지지 않아 1회에 수렴한다. 상관이 있는 가중에서는 한 축을 centering하면 다른 축의 zero-mean이 살짝 깨진다. 다시 고치면 또 깨지지만, 깨지는 양이 매번 일정 비율로 줄어들어 수렴한다.

    Iteration 1¶

    Step 1A — 행(Row) centering

    각 행의 가중평균을 계산해서 \(f_1\)으로 이동한다:

    \[ \bar{r}_0 = \frac{0.3 \times 6 + 0.2 \times 0}{0.3 + 0.2} = \frac{1.8}{0.5} = 3.6 \]
    \[ \bar{r}_1 = \frac{0.2 \times 0 + 0.3 \times 4}{0.2 + 0.3} = \frac{1.2}{0.5} = 2.4 \]

    각 행에서 가중평균을 빼면:

    \[ T_{12} = \begin{pmatrix} 6 - 3.6 & 0 - 3.6 \\ 0 - 2.4 & 4 - 2.4 \end{pmatrix} = \begin{pmatrix} 2.4 & -3.6 \\ -2.4 & 1.6 \end{pmatrix} \]
    \[ f_1 = [+3.6,\; +2.4] \]

    검산:

    • 행0 가중평균: \((0.3 \times 2.4 + 0.2 \times (-3.6)) / 0.5 = 0\) ✓
    • 행1 가중평균: \((0.2 \times (-2.4) + 0.3 \times 1.6) / 0.5 = 0\) ✓
    • 열0 가중평균: \((0.3 \times 2.4 + 0.2 \times (-2.4)) / 0.5 = \mathbf{+0.48}\) ✗
    • 열1 가중평균: \((0.2 \times (-3.6) + 0.3 \times 1.6) / 0.5 = \mathbf{-0.48}\) ✗

    → 행은 깨끗하지만, 열은 아직 zero-mean이 아니다.

    Step 1B — 열(Column) centering

    \[ \bar{c}_0 = +0.48, \quad \bar{c}_1 = -0.48 \]
    \[ T_{12} = \begin{pmatrix} 2.4 - 0.48 & -3.6 + 0.48 \\ -2.4 - 0.48 & 1.6 + 0.48 \end{pmatrix} = \begin{pmatrix} 1.92 & -3.12 \\ -2.88 & 2.08 \end{pmatrix} \]
    \[ f_2 = [+0.48,\; -0.48] \]

    검산:

    • 열0, 열1 가중평균 = 0 ✓
    • 행0 가중평균: \((0.3 \times 1.92 + 0.2 \times (-3.12)) / 0.5 = \mathbf{-0.096}\) ✗

    → 열 centering이 행의 zero-mean을 깨뜨렸다! 비균등 가중이기 때문이다.

    Iteration 2¶

    Step 2A — 행 centering

    \[ \bar{r}_0 = -0.096, \quad \bar{r}_1 = +0.096 \]
    \[ T_{12} = \begin{pmatrix} 2.016 & -3.024 \\ -2.976 & 1.984 \end{pmatrix} \]
    \[ f_1 = [3.504,\; 2.496] \]
    • 행 가중평균 = 0 ✓
    • 열0 가중평균 = +0.0192 ✗ (남아있지만 이전보다 훨씬 작다)

    Step 2B — 열 centering

    \[ \bar{c}_0 = +0.0192, \quad \bar{c}_1 = -0.0192 \]
    \[ T_{12} = \begin{pmatrix} 1.9968 & -3.0048 \\ -2.9952 & 2.0032 \end{pmatrix} \]
    \[ f_2 = [0.4992,\; -0.4992] \]
    • 열 가중평균 = 0 ✓
    • 행0 가중평균 = -0.00384 ✗ (더 작아짐)

    Iteration 3¶

    같은 과정을 반복하면:

    \[ T_{12} \approx \begin{pmatrix} 2.0 & -3.0 \\ -3.0 & 2.0 \end{pmatrix}, \quad f_1 \approx [3.5,\; 2.5], \quad f_2 \approx [0.5,\; -0.5] \]

    행/열 가중평균 ≈ 0. 수렴 완료.

    잔차 수렴 추적¶

    반복 단계 잔여 행 평균 잔여 열 평균 축소율
    1 A (행) 0 ±0.48 —
    1 B (열) ±0.096 0 ×0.2
    2 A (행) 0 ±0.0192 ×0.2
    2 B (열) ±0.00384 0 ×0.2
    3 A (행) 0 ±0.000768 ×0.2
    3 B (열) ≈0 0 ×0.2

    매 half-step마다 잔차가 ×0.2로 줄어든다 — 두 변수의 상관계수 \(\rho = 0.2\)와 정확히 같은 값이다. 3회 반복(6 half-steps) 후 잔차 < 0.001. 같은 구조에서 상관이 0.8이면 축소율도 ×0.8이 되어, 같은 정밀도에 도달하는 데 훨씬 많은 반복이 필요하다(본문 표 참조).

    예측값 보존 검증¶

    \((x_1, x_2)\) Before After: \(f_1 + f_2 + T_{12}^*\) 일치
    (0, 0) 6 3.5 + 0.5 + 2.0 = 6.0 ✓
    (0, 1) 0 3.5 + (−0.5) + (−3.0) = 0.0 ✓
    (1, 0) 0 2.5 + 0.5 + (−3.0) = 0.0 ✓
    (1, 1) 4 2.5 + (−0.5) + 2.0 = 4.0 ✓

    마지막 단계 — main effect의 평균을 intercept로¶

    Purify의 마지막 단계는 main effect의 가중평균을 intercept로 옮기는 것이다. \(X_1\)의 주변 비중은 50:50이므로 \(f_1 = [3.5,\; 2.5]\)의 평균 3.0을 \(f_0\)로 옮기면 \(f_0 = 3.0\), \(f_1 = [+0.5,\; -0.5]\)가 된다. \(f_2 = [+0.5,\; -0.5]\)는 이미 평균이 0이다. 최종 분해는 \(f_0 = 3.0\), \(f_1 = [+0.5, -0.5]\), \(f_2 = [+0.5, -0.5]\), \(f_{12} = [2.0, -3.0;\; -3.0, 2.0]\)이며, (0, 0)에서 \(3.0 + 0.5 + 0.5 + 2.0 = 6.0\)으로 예측이 그대로 보존된다.

    균등 가중과의 비교¶

    같은 tensor에 균등 가중 \(w_{i,j} = 0.25\)를 적용하면:

    • Step 1A (행 centering): \(\bar{r}_0 = 3,\; \bar{r}_1 = 2\)
    • Step 1B (열 centering): \(\bar{c}_0 = 0.5,\; \bar{c}_1 = -0.5\)
    \[ T_{12} = \begin{pmatrix} 2.5 & -2.5 \\ -2.5 & 2.5 \end{pmatrix} \]

    행/열 가중평균 모두 0 → 1회 반복만에 수렴. 이것이 Theorem 1의 상황이다.

    두 가중의 결과가 다르다는 점도 눈여겨볼 만하다. 같은 텐서인데 균등 가중에서는 \(f_{12} = [2.5, -2.5;\; -2.5, 2.5]\), 상관된 가중에서는 \(f_{12} = [2.0, -3.0;\; -3.0, 2.0]\)이 나왔다. 어떤 가중(측도)을 쓰느냐에 따라 "순수 교호작용"의 값 자체가 달라진다.

    균등·독립 가중 상관된 가중
    수렴 1회 반복 반복 필요 (축소율은 상관 강도에 좌우)
    원리 한 축 centering이 다른 축을 안 깨뜨림 한 축 centering이 다른 축을 깨뜨리지만, 깨지는 양이 매번 일정 비율로 감소
    실무 Uniform 가중, 또는 변수 독립(product measure) 가정 시 데이터의 결합 분포(empirical)를 가중으로 쓸 때

    구현

    원논문은 이 알고리즘이 Python 100줄 이내로 구현 가능하다고 밝히고 있다. 공개 라이브러리로는 InterpretML의 purification 유틸리티(interpret.utils.purify, API 문서)와 원저자 그룹의 gam_purification 저장소가 있다.

    어떤 가중(측도)을 쓸 것인가¶

    purification의 결과는 가중치 \(w\)에 의존한다. Lengerich et al. (2020, 5.2절)은 세 가지 추정 방식을 비교했다.

    가중 방식 정의 대응하는 측도
    Uniform 모든 칸에 같은 가중 각 변수의 구간을 균등하게 보는 product measure
    Empirical 학습 데이터에서 각 칸이 차지하는 비중 데이터의 결합 분포(joint measure)
    Laplace Uniform + Empirical (데이터 비중에 균등 가중을 더함) 둘의 절충

    원논문의 순수 교호작용 정의(Definition 1)는 데이터의 실제 분포 \(p(x)\)를 가중으로 쓰는 것이며, 이는 상관된 변수에 대한 일반화 fANOVA(Hooker, 2007)에 해당한다. 반대로 2절의 깔끔한 성질들 — 모든 component 간 직교, 분산 분해 — 은 product measure에서만 그대로 성립한다. 결국 empirical 가중으로 purification하면, 그 결과를 데이터 분포 위에서 분산 분해할 때 component 간 교차공분산이 남는다. 측도 선택에 따라 무엇이 달라지는지는 부록 B 2절에서 수치 예시로 정리한다.

    Purification이 실제로 무엇을 바꾸는가 — 실증 사례¶

    위의 숫자 예시는 원리를 보여주기 위한 것이었다. 실제 데이터에서도 이 정도의 차이가 발생할까? Lengerich et al. (2020, 6절)은 여러 공개 데이터셋에서 purification 전후로 해석이 크게 달라지는 사례를 보고했다. 여기서는 그중 두 가지를 원논문의 서술에 맞춰 소개한다.

    사례 1: California Housing — 바다 위가 가장 비싼 지역? (클릭하여 펼치기)

    1990년 미국 인구조사 기반의 캘리포니아 주택 가격 데이터셋으로 depth-2 XGBoost 모형(원논문의 XGB2)을 학습하고, 위도와 경도의 교호작용을 들여다본 사례다.

    Purification 전: 학습된 그대로의 위도×경도 교호작용 표를 보면, 가장 비싼 부동산이 태평양 바다 위에 있는 것처럼 나타난다 (원논문 Fig.5 왼쪽).

    Purification 후: 같은 표를 정제하면 이 이상한 패턴이 사라지고, 남은 순수 교호작용은 로스앤젤레스와 샌프란시스코 대도시권의 영향으로 정리된다 (Fig.5 가운데).

    왜 이런 일이 생기는가 (해석): 원논문은 현상만 보고하지만, 이 절의 원리로 다음과 같이 설명할 수 있다. 학습된 그대로의 교호작용 표에는 위도나 경도 하나만으로 설명되는 효과(예: 서쪽 해안일수록 비싸다)가 섞여 있다. 또 데이터가 전혀 없는 바다 위 칸에는 트리 경계를 연장한 값이 그대로 채워져 있어, 그 값이 무엇이든 예측 성능에는 영향이 없다. purification이 행·열 방향의 몫을 main effect로 돌려보내면, 교호작용 표에는 두 변수의 특정 조합에서만 나타나는 효과만 남는다.

    출처: Lengerich et al. (2020), 6.2절 California Housing 및 Fig.5. "해석" 문단은 본 가이드북의 설명이다.

    사례 2: COMPAS — 모형과 분해 방식에 따라 main effect의 부호가 갈린다 (클릭하여 펼치기)

    COMPAS는 미국 법원에서 보석 결정 등에 참고하는 재범 위험 예측 시스템이다. Lengerich et al. (2020)은 ProPublica가 공개한 데이터로 교호작용이 있는 가법 모형을 학습하고, 나이·인종·성별·경범죄 여부 등의 main effect를 모형 종류와 purification 가중(Uniform, Empirical, Laplace)별로 비교했다 (원논문 Fig.4).

    원논문이 보고한 것:

    • purification 여부와 purification에 쓰는 분포에 따라 main effect의 크기가 크게 달라지고, 때로는 부호도 달라진다.
    • 특히 교호작용 없이 학습한 XGBoost(depth-1 트리)의 main effect 다수가, GAM이나 purification을 거친 GA2M·depth-2 XGBoost의 main effect와 반대 부호였다. purification한 XGB2의 main effect는 다른 모형들과 훨씬 일관되었다.
    • purification에 쓰는 분포(Uniform·Empirical·Laplace) 사이에서는 주로 main effect의 크기가 상당히 달라졌다.

    원논문은 이 결과로부터, COMPAS 같은 모형을 공정성 관점에서 감사하려면 학습 알고리즘과 purification 분포를 모두 명시해야 한다고 결론짓는다.

    왜 이런 일이 가능한가:

    위의 숫자 예시에서 본 것과 같은 원리다. 소득의 main effect가 0이었는데 purification 후 +0.3/-0.3이 된 것처럼, 교호작용에 누출되어 있던 몫이 원래 main effect보다 클 수 있다. 누출된 양이 원래 main effect와 반대 방향이고 충분히 크면, 정제 후 main effect의 부호가 뒤집힌다.

    출처: Lengerich et al. (2020), 6.1절 COMPAS 및 Fig.4.

    왜 위험한가

    같은 모형, 같은 예측값인데 purification 여부에 따라 "이 변수는 위험을 높인다" vs "이 변수는 위험을 낮춘다"로 해석이 갈린다. 규제 심사역에게 shape function을 보여줄 때, purification을 안 한 결과를 보여주면 틀린 답을 하게 될 수 있다. 알고리즘 공정성 감사에서도 특정 변수의 영향 방향에 대한 판단이 뒤집힐 수 있다.

    모형별 Purification 영향¶

    모형 Interaction 처리 Purification 영향
    XGB depth-1 (= GAM) 없음 교호작용이 구조적으로 없으므로, main effect의 평균을 intercept로 옮기는 중심화만 일어난다
    XGB depth-2 이상 자동 생성, 분리 설계 없음 매우 큼 — main effect 부호까지 변할 수 있음
    GA\(^2\)M (EBM) 2단계 학습으로 분리 시도 대부분 분리되지만 잔여 누출이 남을 수 있어 purification으로 보정 (아래 참조)

    EBM(GA²M)에서의 Purification¶

    EBM은 main effect를 먼저 학습한 뒤, 교호작용 탐지 알고리즘(FAST)으로 고른 변수 쌍의 교호작용을 잔차에 학습하는 2단계 방식으로 main effect와 interaction을 분리한다. 원논문(6절, 6.3절)은 이 방식이 purification으로 옮겨야 할 질량을 줄여주지만, 교호작용 항이 여전히 일부 main effect를 담고 있어 purification이 main effect를 바꾸는 경우가 있다고 보고했다. EBM의 학습 구조와 보정 방법은 EBM (GA²M)에서 상세히 다룬다.

    실무 주의사항 — 분해의 완전성 검증¶

    Purification의 전제는 분해된 효과의 합이 원래 모형의 예측값과 관측치마다 정확히 일치한다는 것이다:

    \[ \hat{f}(\mathbf{x}_i) = f_0 + \sum_{S} f_S(\mathbf{x}_{i,S}) \quad \text{(모든 관측치 } i \text{에 대해)} \]

    이 전제가 깨지면 분해 자체가 무의미하므로, purification 전후로 재구성 오차(모형 예측값과 component 합의 차이)를 전 관측치에서 확인해야 한다. 오차가 부동소수점 누적오차 수준을 넘으면 텐서를 만드는 단계에 문제가 있다는 신호다.

    트리를 직접 순회해 텐서를 만드는 경우, 흔한 원인은 수치 정밀도 불일치다. XGBoost는 입력값과 분할 경계를 내부적으로 단정밀도(float32)로 다루는데, 해석 단계에서 같은 값을 배정밀도(float64)로 비교하면 경계값과 거의 같은 관측치가 학습 때와 다른 leaf로 배정될 수 있다. WoE처럼 고유값이 몇 개뿐인 변수는 분할 경계가 고유값 근처에 놓이는 일이 잦아, 이 문제가 특히 두드러진다. 증상은 "모형 예측값과 재구성 값의 차이가 상수가 아니라 관측치마다 다르다"는 것이다.

    대응은 간단하다. 해석 단계에서 입력값과 분할 경계를 모두 모형과 같은 정밀도(float32)로 반올림한 뒤 비교하면, 학습 때와 같은 leaf 배정을 재현할 수 있다. 모형이 내보내는 분할 경계가 배정밀도 표기로 출력되더라도 내부 값은 단정밀도라는 점에 유의한다.
