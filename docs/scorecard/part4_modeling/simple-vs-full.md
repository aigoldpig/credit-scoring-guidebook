# Simple LR vs Full Model

## 1.1 무엇이 다른가?

[단변량 로지스틱 회귀(Simple LR)](../part3_variable_selection/univariate_lr/concept.md)는 변수 하나하나가 위험을 구분하는지 확인하는 단계였다. Full Model은 선별된 변수들을 **함께** 투입하여 최종 예측 모형을 완성하는 단계다. 두 단계 모두 y=1=Bad(Bad logit)로 적합하며, WoE 변수의 정상 계수는 음수다.

!!! info "Simple LR (단변량)"
    - **목적:** 변수별 유의성(LRT)과 구간 경계(인접 Bin 차이) 확인
    - **방법:** 변수 1개씩 로지스틱 회귀 — 구간별 검정은 One-Hot(절편 없음), 변수 계수는 WoE 치환(절편 포함)
    - **결과:** WoE 치환 계수 \(\hat\beta = -1\) (개발 표본에서 정확히). 구간별로는 \(\hat\beta_i = -\text{WoE}_i + \ln(N_B/N_G)\)
    - **산출물:** 통과/탈락 변수 목록 (IV, LRT, 인접 Bin 차이, 단조성)

!!! success "Full Model (다변량)"
    - **목적:** 변수 간 상호 통제 후 고유 효과 추출
    - **방법:** 통과 변수 전체 동시 투입, 절편 포함
    - **결과:** \(\hat{\beta}_{\text{multi}}\)는 보통 −1과 0 사이 — 상관 변수와 정보를 나눈 만큼 축소
    - **산출물:** 최종 회귀계수 → 스코어카드 부분점수

핵심 차이는 **변수 간 상관(다중공선성)** 의 통제 여부다. 단변량에서는 서로 상관된 두 변수가 모두 높은 IV를 보일 수 있지만, Full Model에서는 둘 중 하나가 중복 정보로 판정되어 β가 크게 줄거나 부호가 뒤집혀 제거된다.

!!! tip "직관적 비유"
    매출액과 총자산은 단독으로 보면 각각 불량 예측에 강한 신호를 보인다. 그러나 둘은 상관이 매우 높으므로(같은 기업 규모를 다른 각도에서 잰 값), 함께 투입하면 한 변수가 상대방의 정보를 대부분 설명해 버린다. 결과적으로 한 변수의 \(\lvert\beta\rvert\)가 크게 줄거나, 심하면 부호가 양(+)으로 역전된다. 이 예시는 [Partial LR](../part3_variable_selection/domain_selection/partial-lr.md)에서 실제로 다룬다.

## 1.2 왜 Simple LR 단계를 생략할 수 없는가?

Simple LR 없이 바로 Full Model을 구성하면 다음 문제가 생긴다.

| 문제 | 설명 |
|------|------|
| **변수 과다 투입** | 후보 변수가 30~50개일 때 한꺼번에 다변량 회귀를 수행하면 다중공선성이 커져 β 추정이 불안정해진다 |
| **불량 변수 혼입** | IV가 낮거나 WoE 패턴이 비단조적인 변수가 걸러지지 않은 채 Full Model에 진입 → 노이즈가 모형 성능을 저하 |
| **Classing 품질 미검증** | 인접 구간이 통계적으로 구분되는지 확인하지 않으면, 근거 없는 경계가 점수표에 그대로 남는다 |
| **디버깅 난이도 증가** | Full Model에서 β 부호 역전이 발생해도, 원인이 다중공선성인지 Classing 문제인지 변수 자체의 문제인지 구분하기 어려움 |

Simple LR은 이 문제를 걸러내는 **사전 필터링 + 품질 보증** 단계다. 변수별 검증(LRT, 인접 Bin 차이, 단조성)을 마친 변수만 Full Model에 투입하므로, Full Model 단계에서 생기는 문제의 원인을 **"변수 간 상관"** 으로 좁힐 수 있다.

## 1.3 Simple LR → Full 전환 시 달라지는 것

| 항목 | Simple LR | Full Model |
|------|-------------|------------|
| **절편** | 구간 검정용 One-Hot은 없음 / WoE 치환은 있음 | 있음 (\(\beta_0\) 포함) |
| **계수 해석** | 변수 단독 효과 (WoE 치환 계수 = −1) | 다른 변수를 통제한 고유 효과 |
| **계수 크기** | 정확히 −1 | 보통 −1과 0 사이. 양수면 역전, \(\lvert\beta\rvert > 1\)이면 주의 |
| **변수 수** | 1개씩 개별 투입 | 최종 후보 전체 동시 투입 |
| **다중공선성** | 해당 없음 | VIF로 진단·제거 |
| **산출물** | 통과 변수 목록 | 최종 회귀계수 → [스코어카드](../part5_scorecard/scorecard-and-rating.md) |

!!! note "Classing 피드백 루프와의 관계"
    Simple LR에서 구분되지 않는 인접 Bin이 발견되면 [Classing 피드백 루프](../part3_variable_selection/univariate_lr/feedback-loop.md)를 통해 Coarse Classing을 재조정한다. 이 피드백이 끝난 뒤에야 Full Model 투입 변수가 확정된다. 즉 Simple LR → Classing 피드백 → Simple LR 재확인 → 정보영역별 선정 → Full Model이라는 **반복적 흐름**이 실무의 표준이다.
