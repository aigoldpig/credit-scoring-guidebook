# Classing 의사결정 기준 종합

Fine → Coarse Classing 전 과정에서 아래 기준표를 순서대로 적용한다. **Bin 크기 기준은 이 표가 가이드북 전체의 정본**이며, 다른 페이지는 이 표를 참조한다.

## 기준값 정본 — Bin 크기와 합병 기준

<div markdown>

| 단계 | 확인 항목 | 기준값 | 조치 |
|------|----------|--------|------|
| **Fine Classing** | 구간 수 | 20~50개 (구간당 전체의 약 2~5%) | 탐색용. **최소 비중 기준은 적용하지 않는다** |
| | 특수값 분리 | 결측·특수코드·Mass Point는 별도 Bin | 이상치는 양 끝 Bin에 흡수 |
| | 얇은 구간 표시 | Bad 건수가 매우 적은 구간(예: 10건 미만) 표시 | Coarse 단계의 합병 후보로 넘김 |
| **Coarse Classing** | Bin 비중 | **각 Bin ≥ 전체의 5%** | 미달 Bin → 인접 Bin과 합병. 단, 연체 경험처럼 보유율이 낮은 정보는 Bad 건수가 충분하고 인접 Bin과 불량률 차이가 뚜렷하면 유지를 검토하고, 시점별로 흔들리면 위험 쪽 Bin에 합친다 |
| | Bin별 Bad 건수 | **최소 10건, 권장 30건 이상** | 10건 미만은 반드시 합병, 10~30건은 합병 검토 |
| | 최종 Bin 수 | 3~10개 (통상 5개 안팎) | 이진 변수는 2개 허용 |
| | WoE 단조성 | 단조증가 또는 단조감소 | 위반 구간 합병 (명확한 업무 논리의 U자형은 문서화 후 예외) |
| | 인접 Bin 구분 | Delta WoE(경험칙 0.05~0.1) + 인접 Bin 차이 검정 | 차이가 비유의면 합병 검토 — [정본: 유의성 검정](../univariate_lr/significance-test.md) |
| | 업무 논리 | 경제적 해석 가능 | 통계 기준 통과 후 업무 논리로 조정 |
| **최종 확정** | 후보안 비교 | 단조성, 인접 Bin 구분, 변수 LRT, KS | 단변량 LR 결과 반영 |

</div>

Bad 건수 기준의 근거(표본 변동)는 [WoE 1.7절](../woe_iv/woe.md)에서 다룬다.

## 4.1 각 기준의 근거와 위반 시 위험

### Coarse Bin 최소 비중 (≥ 5%)

Bin에 데이터가 너무 적으면 해당 구간의 Bad Rate와 WoE가 **표본 변동에 지배**된다. 개발 표본에서 우연히 WoE가 높게 나왔더라도, 검증 표본이나 실제 운영에서는 전혀 다른 값이 나올 수 있다.

!!! warning "위반 시 위험"
    소규모 Bin의 WoE가 불안정하면 모형 계수(β)도 불안정해진다. 작은 Bin은 구성비가 조금만 움직여도 변수 안정성 지표(CSI)가 크게 흔들리므로, 운영 중 모니터링 경보가 잦아지고 조기 재개발 판단을 앞당길 수 있다.

### Bin별 Bad 건수 (최소 10건, 권장 30건)

Bad Rate의 표준오차는 Bad 건수에 크게 좌우된다. Bad가 0~2건이면 WoE가 무한대로 발산하거나(Bad = 0), Bad 1건의 차이에도 WoE가 크게 바뀐다. 예를 들어 Bad 5건인 Bin에서 1건이 달라지면 Bad 건수가 20% 변하고, WoE는 약 0.2 움직인다(ln(6/5) ≈ 0.18).

!!! warning "위반 시 위험"
    Bad = 0인 Bin에 0.5 스무딩을 적용해도 WoE의 신뢰성은 낮다. 이런 Bin이 모형에 들어가면 **해당 구간 고객의 점수가 비현실적으로 높거나 낮아지는** 현상이 생긴다.

### WoE 단조성

WoE가 단조적이어야(Bin 순서에 따라 WoE가 일관되게 증가 또는 감소) 변수의 리스크 방향이 명확하다. 비단조 WoE는 "매출이 늘다가 줄다가 다시 늘면 위험하다"는 식의 해석하기 어려운 패턴을 뜻한다.

!!! warning "위반 시 위험"
    비단조 WoE를 가진 변수가 스코어카드에 들어가면 **리스크 방향의 비일관성** 문제가 생긴다. 심사역·내부 검증·감독 검토에서 설명을 요구받는 대표적인 지적 사항이며, 표본 변동으로 생긴 역전은 검증 표본에서 재현되지 않는 경우가 많다.

### 인접 Bin 구분 (Delta WoE + 차이 검정)

인접 Bin 간 WoE 차이가 작으면 두 Bin은 리스크 수준이 사실상 같다. 구간을 나눈 의미가 없고 Bin 수만 늘린다. 다만 Delta WoE는 **표본 크기를 반영하지 않는** 경험칙이므로, 같은 0.07이라도 표본이 크면 유의하고 작으면 비유의할 수 있다. 그래서 최종 판단은 인접 Bin 차이 검정(χ² 또는 Wald)으로 한다.

!!! warning "위반 시 위험"
    구분되지 않는 Bin이 남아 있으면 그 경계는 노이즈를 신호처럼 반영한다. 검증 표본에서 두 Bin의 순서가 뒤집히기 쉽고, 불필요한 Bin은 스코어카드를 복잡하게 만든다.

### 개별 Bin의 Wald p-value는 합병 기준이 아니다

구간별 계수가 "전체 평균(WoE = 0)과 다른가"는 합병 판단과 다른 질문이다. WoE ≈ 0인 중간 구간은 평균과 구분되지 않는 것이 정상이다. 변수 전체의 LRT가 유의하고 단조성이 유지되면 이런 Bin은 그대로 둔다. 이 규칙의 정본은 [유의성 검정](../univariate_lr/significance-test.md)이다.

### 업무 논리 (경제적 해석 가능성)

모든 통계 기준을 충족하더라도 비즈니스 관점에서 해석할 수 없는 Classing은 심사역과 감독기관을 설득하기 어렵다. 예를 들어 "매출액 30~50억 구간만 유독 위험하고, 그보다 크거나 작은 구간은 안전하다"는 패턴(위험 기준 역U자형)은 통계적으로 유의하더라도 경제적으로 설명하기 어렵다.

## 4.2 기준 충돌 시 해결 방법

실무에서는 여러 기준이 동시에 충족되지 않는 상황이 빈번하다.

| 충돌 상황 | 해결 방향 |
|-----------|----------|
| **단조성은 만족하지만 최소 건수 미달** | 인접 Bin과 합병하여 표본을 확보한다. 합병 후에도 단조성이 유지되는 방향(Bad Rate가 더 가까운 인접 Bin)으로 합친다. |
| **최소 건수는 충족하지만 단조성 위반** | 단조성을 위반하는 구간끼리 합병한다. 합병 후에도 해소되지 않으면 Classing 자체를 재설계하거나 변수 제거를 검토한다. |
| **인접 Bin 차이가 비유의하지만 업무상 필요한 경계** | 업무 논리가 명확하면(예: "연체 0건"과 "연체 1건 이상"의 구분) 유지할 수 있다. 단, 모형 문서에 "업무 논리에 의한 예외"로 명기하고 검증 표본에서 순서가 유지되는지 별도 확인한다. |
| **Delta WoE가 작지만 표본이 커서 차이는 유의** | 통계적으로는 구분된다. Bin 수 상한, 해석 부담, IV 손실을 함께 보고 결정한다. 합병 후 IV 하락이 미미하면 합병이 낫다. |

## 4.3 Worked Example: "Bin 3과 Bin 4를 합쳐야 하는가?"

매출액 변수의 Coarse Classing 결과가 다음과 같다고 하자(가상 예시, 전체 Good 7,300 / Bad 434).

| Bin | 매출액 범위 | Good | Bad | Bad Rate | WoE | Delta WoE |
|-----|-----------|------|-----|----------|-----|-----------|
| 1 | 1억 미만 | 800 | 120 | 13.04% | −0.925 | — |
| 2 | 1억~5억 | 1,200 | 100 | 7.69% | −0.338 | 0.588 |
| 3 | 5억~10억 | 1,500 | 80 | 5.06% | +0.109 | 0.446 |
| **4** | **10억~30억** | **1,800** | **89** | **4.71%** | **+0.184** | **0.076** |
| 5 | 30억 이상 | 2,000 | 45 | 2.20% | +0.972 | 0.787 |

전체 IV = 0.352

**문제**: Bin 3 → Bin 4의 Delta WoE = 0.076으로 경험칙(0.05)은 넘지만 경계선이다. 합병해야 하는가?

**판단 과정**:

1. **표본·단조성**: 모든 Bin이 5% 이상이고 Bad 45건 이상, WoE 단조 증가 → 통과
2. **개별 Bin vs 평균**: Bin 3(p = 0.34)과 Bin 4(p = 0.09)는 "WoE = 0(전체 평균과 같음)"을 기각하지 못한다. 그러나 이것은 **합병 근거가 아니다**(중간 구간은 평균에 가까운 것이 정상).
3. **인접 Bin 차이 검정 (핵심)**: Bin 3 vs Bin 4의 Bad Rate 차이는 χ² = 0.23, **p = 0.63** → 두 구간의 위험은 통계적으로 구분되지 않는다. (다른 인접 쌍은 모두 p < 0.01)
4. **합병 시뮬레이션**: Bin 3+4 합병 후 Bad Rate 4.87%, WoE = +0.149

| 지표 | 합병 전 (Bin 3, 4 분리) | 합병 후 (Bin 3+4 통합) |
|------|----------------------|---------------------|
| Bin 수 | 5 | 4 |
| 전체 IV | 0.352 | 0.352 (−0.2%) |
| 인접 Bin 차이 비유의 쌍 | 1쌍 (Bin 3-4) | 0쌍 (모든 인접 쌍 p < 0.001) |
| 단조성 | 유지 | 유지 |

**결론**: 합병해도 IV는 사실상 그대로(0.3522 → 0.3516)이고, 구분되지 않던 경계가 사라진다. **합병이 바람직하다.**

계산 재현: 이 페이지의 모든 수치는 표의 Good/Bad 건수에서 직접 계산한 값이다.

    Classing은 한 번에 완성되지 않는다. [단변량 로지스틱 회귀](../univariate_lr/index.md)에서 인접 Bin이 구분되지 않거나 단조성이 의심되면 Coarse Classing으로 돌아가 구간을 재조정한다. 상세 절차는 [Classing 피드백 루프](../univariate_lr/feedback-loop.md)를 참고한다.
