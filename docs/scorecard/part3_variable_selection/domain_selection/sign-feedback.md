# β 부호 이상과 범주 재조정

## 2.1 영역 내 회귀에서 부호가 뒤집히는 이유

WoE = ln(%Good/%Bad)를 Bad logit 모형에 넣으면 정상 계수는 **음수**다(단변량에서 정확히 −1). 영역 내 Partial LR에서 이 계수가 **양수(+)로 바뀌면 "부호 역전"** 이다. 역전의 가장 흔한 원인은 **같은 영역 안의 다중공선성**이다.

### 왜 상관 변수가 들어오면 계수가 바뀌는가

선형회귀(OLS)에서는 누락변수 편의(omitted variable bias) 공식으로 정확히 설명된다. 변수 \(X_j\) 하나만 넣은 단변량 계수와, 다른 변수 \(X_k\)를 함께 넣은 다변량 계수 사이에는

$$
\hat{\beta}_j^{\text{uni}} = \hat{\beta}_j^{\text{multi}} + \sum_{k \neq j} \hat{\delta}_{kj}\, \hat{\beta}_k^{\text{multi}} \tag{1}
$$

가 성립한다. 여기서 \(\hat{\delta}_{kj}\)는 \(X_k\)를 \(X_j\) 하나로 단순회귀(절편 포함)했을 때의 기울기, 즉 "\(X_j\)가 \(X_k\)를 얼마나 대신 나타내는가"다. 단변량 계수에는 상관 변수들의 효과가 섞여 있고(우변 둘째 항), 다변량 계수는 그 몫을 뺀 **고유 효과**다.

매출액(\(X_k\))과 총자산(\(X_j\))처럼 상관이 높으면(\(\hat\delta_{kj}\)가 큼), 총자산의 단변량 계수 −1의 대부분은 사실 매출액의 효과다. 매출액을 함께 넣으면 그 몫이 빠지고, 남은 고유 효과가 0 근처의 작은 값이 되어 표본 변동에 따라 양수로 넘어갈 수 있다.

!!! note "로지스틱 회귀에서는 근사적으로 성립한다"
    로지스틱 회귀에서는 식 (1)이 정확히 성립하지 않는다(로짓 모형의 비붕괴성, non-collapsibility — 상관이 없는 변수를 추가해도 계수가 커질 수 있다). 다만 "상관 변수가 단변량 효과를 나눠 가진다"는 방향성은 같으므로, 부호 역전을 해석하는 틀로 쓸 수 있다.

!!! info "부호 역전의 주요 원인"
    1. **강한 다중공선성** (가장 흔함) — 매출액과 총자산처럼 상관이 높은(예: r > 0.7) 변수 쌍. VIF로 확인된다.
    2. **억제(Suppressor) 효과** — 변수 A가 단독으로는 약하지만, B와 함께 넣으면 B의 잡음을 걷어내는 역할을 한다. 이때 A의 계수는 반대 부호를 가질 수 있다. VIF가 높지 않아도 생긴다.
    3. **WoE 단조성 위반·구간 불안정** — Coarse Classing의 단조성이 불완전하거나 일부 구간 표본이 얇으면, 다변량에서 계수가 불안정해진다.
    4. **표본 편향** — 특정 하위집단이 과다·과소 표집되어 변수와 위험의 관계가 왜곡된 경우.

## 2.2 범주 재조정 피드백 루프

영역 내 Partial LR에서 β가 양(+)으로 나타나면, 원인을 진단한 뒤 변수 제거 또는 **범주 재조정** 후 해당 영역의 Partial LR을 다시 적합한다.

구체적인 절차:

```
β 부호 양(+) 발견 (= 역전)
    │
    ├─→ [원인 1] 다중공선성 점검: VIF 확인
    │       ├─ VIF ≥ 5 → 상관 변수 쌍 중 하나 제거(IV 낮은 쪽·부호 이상 쪽) → 재적합
    │       └─ VIF < 5 → 원인 2~4 검토
    │
    ├─→ [원인 2] 억제효과 의심 (VIF 낮은데 역전)
    │       └─ 변수를 하나씩 빼며 β 변화 확인 → 업무 논리로 설명 안 되면 제거
    │
    ├─→ [원인 3] WoE 단조성 위반 또는 구간 불안정
    │       └─ 범주 재조정 (Coarse Classing 재설계)
    │              ├─ 문제 구간 합병 또는 경계 이동
    │              ├─ WoE 재산출
    │              └─ 영역 내 Partial LR 재적합
    │
    ├─→ [원인 4] 표본 편향
    │       └─ 표본 설계·제외 기준 재확인
    │
    └─→ 위 조치 후에도 역전 지속
            └─ 해당 변수 제거
```

## 2.3 범주 재조정이란?

범주 재조정(Bin Restructuring)은 [Coarse Classing](../classing/coarse-classing.md)을 **수정**하는 것이다. 단변량 단계에서 확정한 Classing이 다변량 맥락에서 문제를 일으킬 때 수행한다.

### 주요 재조정 기법

<div class="review-item" markdown>
  <span class="review-badge">1</span>
  <span class="review-title">문제 구간 합병</span>
</div>

WoE 단조성을 깨는 구간, 또는 표본이 매우 적은 구간을 인접 구간과 합병한다. 아래는 부채비율 5구간(각 2,000건, 가상 예시)에서 Bin 3의 불량률이 튀어 단조성이 깨진 경우다.

| 변경 전 | Bad Rate | WoE | 변경 후 | Bad Rate | WoE |
|---------|----------|-----|---------|----------|-----|
| Bin 1 | 2.10% | +0.967 | Bin 1 | 2.10% | +0.967 |
| Bin 2 | 3.50% | +0.442 | Bin 2 | 3.50% | +0.442 |
| **Bin 3** | **7.20%** | **−0.319** | **Bin 3+4** | **6.15%** | **−0.150** |
| **Bin 4** | **5.10%** | **+0.049** | *(합병)* | | |
| Bin 5 | 8.80% | −0.537 | Bin 4 | 8.80% | −0.537 |

→ Bin 3의 급등과 Bin 4의 반등이 합병으로 상쇄되어 불량률 2.1% → 3.5% → 6.15% → 8.8%, WoE +0.97 → +0.44 → −0.15 → −0.54로 **단조성이 복원**된다. (불량률이 높을수록 WoE가 음수로 내려간다 — WoE 정의와 일치)

Bin 2+3을 합치면 불량률이 5.35%가 되어 Bin 4(5.10%)보다 여전히 높으므로 단조성이 복원되지 않는다. **어느 쪽과 합칠지는 합병 후 단조성으로 판단한다.**

<div class="review-item" markdown>
  <span class="review-badge">2</span>
  <span class="review-title">구간 경계 이동</span>
</div>

특정 경계값이 업무적으로 의미 있는 임계치(예: 부채비율 200%)에 맞지 않을 경우 경계를 조정한다.

<div class="review-item" markdown>
  <span class="review-badge">3</span>
  <span class="review-title">변수 자체 재설계</span>
</div>

원시 변수의 정의를 바꾼다. 예를 들어 "총 연체건수"를 "최근 12개월 연체건수"로 기간을 한정하거나, 비율 변수의 분모를 바꾼다. (로그 변환은 순서를 바꾸지 않으므로 등빈도 구간화 결과는 같다. 등간격 구간화를 쓸 때만 효과가 있다.)

!!! warning "범주 재조정 후 반드시 재확인할 항목"
    1. WoE 단조성 유지 여부
    2. IV 수준 유지 여부 (재조정으로 IV가 급감하면 변수의 변별력이 훼손된 것)
    3. 구간별 최소 표본 기준 충족 여부 ([기준값 정본](../classing/decision-criteria.md))
    4. 단변량 LR: 변수 LRT와 인접 Bin 차이 검정 ([유의성 검정](../univariate_lr/significance-test.md))

## 2.4 재적합 후 판정

범주 재조정 후 해당 영역의 Partial LR을 **처음부터 다시** 수행한다.

| 시나리오 | 조치 |
|---------|------|
| β 음수로 복원 + p < 0.05 + VIF < 5 | ✅ 대표 변수로 확정 |
| β 음수이나 p ≥ 0.05 | 변수 제거 (유의성 부족) |
| 재조정 후에도 β 양수 지속 | 변수 제거 (정보 중복 해소 불가) |
| IV가 재조정 전보다 크게 감소 (예: 30% 이상) | 재조정이 과도 → 원래 Classing으로 복원 후 변수 제거 검토 |

!!! tip "실무 판단 기준"
    범주 재조정은 **1~2회** 시도하는 것이 일반적이다. 반복적인 재조정은 개발 표본에 과적합할 위험이 있다. 2회 시도 후에도 부호가 정상화되지 않으면, 해당 변수는 같은 영역의 다른 변수와 **정보가 중복**되는 것으로 보고 제거하는 것이 합리적이다.

## 2.5 전체 흐름 요약

```
단변량 LR 통과 변수 (20~30개)
    │
    ▼
정보영역별 그룹 분류
    │
    ▼
영역별 Partial LR + 단계적 선택 ──→ β 음수(정상) + 유의 → 대표 변수 확정
    │                                                │
    ▼                                                │
β 양수(역전) 발견                                    │
    │                                                │
    ├─ VIF ≥ 5 → 상관 변수 제거 → 재적합 ──────────→ │
    │                                                │
    └─ VIF < 5 → 억제효과 점검 / 범주 재조정 → 재적합 → │
                                                     │
                                                     ▼
                            영역별 대표 변수 확정 (영역당 1~3개)
                                                     │
                                                     ▼
                            전체 통합 → Full Model (Part 4)
```

모든 영역의 대표 변수가 확정되면, 이를 통합하여 [다변량 WoE 로지스틱 회귀(Full Model)](../../part4_modeling/multivariate-regression.md)를 구성한다.
