# 유의성 검정

이 페이지는 **비유의 Bin 처리 기준의 정본**이다. Classing·단변량 LR·피드백 루프의 다른 페이지는 이 기준을 참조한다.

## 4.1 Wald 검정 — 무엇을 검정할 것인가

절편 없는 One-Hot 모형에서는 구간마다 계수 \(\hat\beta_i\)와 표준오차가 나온다([식 (2)](one-hot-no-intercept.md)). Wald 통계량의 일반형은 다음과 같다.

$$
W = \left(\frac{\hat\theta - \theta_0}{\widehat{SE}(\hat\theta)}\right)^2 \sim \chi^2(1) \quad \text{under } H_0: \theta = \theta_0 \tag{1}
$$

핵심은 **\(\theta\)와 \(\theta_0\)를 무엇으로 잡느냐**다. 세 가지 선택지가 있다.

| 검정 | 귀무가설 | 의미 | 쓰임 |
|------|---------|------|------|
| **(a) 기본 출력** | \(\beta_i = 0\) | 이 구간의 불량률이 50% | **쓰지 않는다** (불균형 표본에서 무의미) |
| **(b) 평균 대비** | \(\beta_i = \ln(N_B/N_G)\) ⇔ \(\text{WoE}_i = 0\) | 이 구간의 위험이 전체 평균과 같다 | 보조 정보 |
| **(c) 인접 Bin 대비** | \(\beta_i = \beta_{i+1}\) | 이웃한 두 구간의 위험이 같다 | **합병 판단의 기준** |

(c)의 통계량은 \(\hat\theta = \hat\beta_i - \hat\beta_{i+1}\), \(\widehat{SE} = \sqrt{SE_i^2 + SE_{i+1}^2}\)(두 구간은 서로 다른 고객이라 독립)로 계산한다. 이는 두 구간의 2×2 표에 대한 카이제곱 검정(ChiMerge의 검정)과 같은 가설을 보며, 대표본에서 거의 같은 값을 준다.

### 매출액 5구간에 적용 (Good 1,000 / Bad 200)

| Bin | \(\hat{\beta}_i\) | SE | (a) \(H_0:\beta_i=0\) p | (b) 평균 대비 p | (c) 다음 Bin 대비: 차이 / p |
|-----|-----|-----|-----|-----|-----|
| 1 (1억 미만) | +0.182 | 0.191 | 0.341 | < 0.001 | +1.281 / < 0.001 |
| 2 (1억~5억) | −1.099 | 0.163 | < 0.001 | 0.002 | +0.511 / 0.032 |
| 3 (5억~10억) | −1.609 | 0.173 | < 0.001 | 1.000 | +0.847 / 0.001 |
| 4 (10억~50억) | −2.457 | 0.190 | < 0.001 | < 0.001 | +0.069 / **0.818** |
| 5 (50억 초과) | −2.526 | 0.232 | < 0.001 | < 0.001 | — |

!!! warning "(a) 기본 출력이 틀린 답을 주는 이유"
    \(\beta_i = 0\)은 "불량률 50%"다. 이 데이터의 전체 불량률은 16.7%이므로, (a)는 "이 구간이 50%와 다른가"를 묻는 셈이다. 그 결과 **가장 위험한 Bin 1**(불량률 54.5%)이 50%에 가까워 p = 0.341로 "비유의"가 되고, 나머지는 모두 "유의"가 된다. 통계 패키지 summary의 p-value를 그대로 쓰면 이런 결론이 나온다. (a)가 (b)와 같아지는 것은 Bad:Good = 1:1 균형 표본일 때뿐이다.

!!! note "(b) — 중간 구간이 평균과 같은 것은 정상이다"
    Bin 3은 WoE = 0이라 (b)의 p = 1.000이다. 구간이 여러 개면 가운데 구간의 불량률이 전체 평균에 가까운 것이 자연스럽다. 이 구간을 "비유의"라는 이유로 합치면 단조 흐름의 중간 단계가 사라져 정보만 잃는다. (b)는 각 구간의 위험 수준을 설명하는 보조 정보로만 쓴다.

!!! success "(c) — 합병 판단은 인접 Bin 차이로 한다"
    Bin 4와 Bin 5는 불량률 7.9% vs 7.4%, 차이 검정 p = 0.818로 **구분되지 않는다**. 두 구간을 나눠 둘 통계적 근거가 없으므로 합병을 검토한다. 나머지 인접 쌍은 모두 p < 0.05다. 합병 과정은 [Classing 피드백 루프](feedback-loop.md)에서 이어진다.

## 4.2 우도비 검정(LRT) — 변수 전체 유의성

변수 전체가 위험을 구분하는지 검정한다. 절편만 있는 모형(Null)과 변수를 넣은 모형(Full)의 로그우도를 비교한다.

!!! note "LRT 귀무가설과 대립가설"
    - **귀무가설 \(H_0\):** \(\beta_1 = \beta_2 = \cdots = \beta_k\) — 모든 구간의 위험이 같다 (= 변수가 쓸모없다)
    - **대립가설 \(H_1\):** 적어도 두 구간의 위험이 다르다
    - "모든 \(\beta_i = 0\)"이 아니다. 그것은 "모든 구간의 불량률이 50%"라는 무의미한 가설이다.

$$
\text{LR} = -2\left[\ell(\text{Null}) - \ell(\text{Full})\right] \sim \chi^2(k-1) \tag{2}
$$

자유도는 **추가된 모수의 수**다. Full(절편 없는 One-Hot)은 모수 \(k\)개, Null(절편만)은 1개이므로 \(df = k-1\)이다. 절편 포함 \(k-1\) 더미 모형으로 계산해도 같은 값이 나온다.

**매출액 예시:** \(\ell(\text{Full}) = -472.64\), \(\ell(\text{Null}) = -540.67\) → LR = 136.07, df = 4, 임계값(5%) 9.49 → p < 0.001. 변수는 유의하다.

!!! tip "LRT 적용 예시 — 3개 구간 변수"
    "업력" 변수를 3개 구간(3년 미만, 3~10년, 10년 초과)으로 나누었다고 하자.

    1. **Null Model:** 절편만 있는 모형 → \(\ell(\text{Null})\)
    2. **Full Model:** 업력 3개 더미(절편 없음) 또는 2개 더미 + 절편 → \(\ell(\text{Full})\)
    3. **검정:** \(\text{LR}\)을 자유도 \(df = 3 - 1 = 2\)인 카이제곱 분포와 비교. 5% 임계값은 **5.99**

    LR이 5.99를 넘으면 업력의 구간들이 위험을 구분한다고 판단한다.

!!! warning "Null Model은 '절편만 있는 모형'"
    LRT의 Null Model은 **절편만 포함한 모형**이다. "절편도 없는 빈 모형"(모든 고객 불량률 50%)이 아니다. Null Model의 절편은 전체 log-odds \(\ln(N_B/N_G)\)를 추정하며, LRT는 "구간을 나눔으로써 이 평균 수준 대비 얼마나 설명력이 늘었는가"를 검정한다.

!!! warning "WoE 치환 모형으로 LRT를 할 때"
    WoE 변수 하나를 넣은 모형은 모수가 하나 늘어날 뿐이지만, WoE 값 자체가 같은 표본에서 \(k-1\)개의 구간 정보를 써서 만들어졌다. LR 값은 One-Hot 모형과 같으므로 **자유도도 \(k-1\)** 로 잡아야 한다. 자유도 1로 검정하면 유의성이 과장된다.

### 검정 방법 비교

| 검정 | 비교 대상 | 귀무가설 예 | 언제 사용 | 특징 |
|------|----------|---------|---------|------|
| **Wald** | 추정치와 SE | 인접 Bin 동일 \(\beta_i = \beta_{i+1}\) | 구간 경계 진단 | 한 번의 적합으로 계산. 대표본에서 신뢰도 높음 |
| **LRT** | Null vs Full 로그우도 | 모든 구간 동일 | 변수 전체 유의성 | Wald보다 소표본에서 안정적 |
| **Score** | Null 모형에서의 기울기 | LRT와 같음 | 변수 추가 여부를 빠르게 판단 | LRT와 점근적으로 동일, Full 모형을 적합하지 않아도 됨 |

## 4.3 비유의 Bin 처리 기준 (정본)

| 상황 | 판단 | 조치 |
|------|------|------|
| 변수 LRT 비유의 (p ≥ 0.05) | 변수가 위험을 구분하지 못함 | Classing 재설계 또는 변수 제거 |
| 변수 LRT 유의 + 단조성 유지 + 개별 Bin이 평균과 구분 안 됨((b) 비유의) | 정상 (중간 구간) | **유지** |
| 인접 Bin 차이 비유의((c) p ≥ 0.05) | 두 구간을 나눌 근거 없음 | **합병 검토** → 합병 후 단조성·IV·LRT 재확인 |
| 인접 Bin 차이 비유의이지만 업무상 필요한 경계 | 업무 논리 예외 | 유지 가능. 모형 문서에 예외로 명기하고 검증 표본에서 순서 유지 확인 |
| 단조성 위반 | 리스크 방향 불명확 | 위반 구간 합병 ([의사결정 기준](../classing/decision-criteria.md)) |

!!! note "실무 기준값"
    - 변수 전체 LRT: p < 0.05
    - 인접 Bin 차이: p < 0.05이면 경계 유지. 표본이 매우 큰 경우(수십만 건)에는 미세한 차이도 유의해지므로, Delta WoE(경험칙 0.05~0.1)와 IV 손실을 함께 본다.
    - p-value는 가이드라인이다. 업무 중요도·IV·단조성과 함께 종합 판단한다.

## 4.4 단변량 로지스틱 회귀 결과 해석 매트릭스

| 확인 항목 | 결과 | 판단 | 조치 |
|-----|---------|------|------|
| \(\hat\beta_i + \text{WoE}_i\) | 모든 구간에서 \(\ln(N_B/N_G)\)로 같음 | 계산 정상 | — |
| \(\hat\beta_i + \text{WoE}_i\) | 구간마다 다름 | **집계·코딩 오류** (Classing 문제 아님) | Good/Bad 집계, 구간 매핑, 목표변수 정의 재확인 |
| 변수 LRT | p < 0.05 | 변수 유의 | 다음 확인으로 |
| 변수 LRT | p ≥ 0.05 | 변수 무의미 | Classing 재설계 또는 제거 |
| 인접 Bin 차이 | 모두 p < 0.05 | Classing 양호 | 유지 |
| 인접 Bin 차이 | 일부 p ≥ 0.05 | 경계 근거 부족 | 합병 후 재검정 ([피드백 루프](feedback-loop.md)) |
| \(\hat\beta\) 순서 | 단조 | 리스크 방향 명확 | 유지 |
| \(\hat\beta\) 순서 | 비단조 | 단조성 위반 | 위반 구간 합병 |
