# 부록 B: 로지스틱 회귀 투입 방식 & Stepwise 검정 이론

> WoE 직접 투입 vs 더미 변수 방식의 차이 · Stepwise 단계별 검정 원리 · Score / Wald / LR Test 직관적 해설

!!! note "이 부록의 위치와 부호 규약"
    본문 Part 3~4의 흐름을 전제로, **로지스틱 회귀 투입 단계의 기술적 깊이**를 정리한다. 모든 페이지는 [부록 공통 부호 규약](../index.md)을 따른다: WoE \(= \ln(\%\text{Good}/\%\text{Bad})\), 적합은 Bad logit, WoE 계수의 정상 부호는 \(\beta<0\), 최위험 구간을 기준으로 한 더미 계수는 안전한 구간일수록 \(\gamma<0\). 점수 변환 배점은 \(-B\cdot\beta\cdot\text{WoE}\)(\(B = \text{PDO}/\ln 2\))다.

## 두 방식의 전체 구조

본문 [Classing](../../part3_variable_selection/classing/index.md)과 [WoE·IV](../../part3_variable_selection/woe_iv/index.md)에서 변수를 구간화하고 WoE/IV를 계산한다. 이후 로지스틱 회귀 투입 단계에서 두 방식이 갈라진다.

<div class="cbox-title">방식 ① WoE 직접 투입</div>

- 구간별 WoE 수치를 **연속형 숫자**로 회귀에 투입
- 변수당 계수(\(\beta\)) 1개 추정

</div>

<div class="cbox-title">방식 ② 더미 변수 방식</div>

- 구간 번호(0,1,2…)를 **범주형**으로 선언, 더미 자동 생성
- 변수당 계수(\(\gamma\)) (구간수−1)개 추정
- 국내 은행 실무에서도 사용
</div>
</div>

!!! warning "더미 방식의 구간 코딩"
    실무에서 구간화 결과는 구간 번호(정수)로 코딩된다. 예를 들어 DSR 변수는 위험도 순서대로 0(≥70%, 최위험), 1(30~70%), 2(<30%, 안전)으로 매핑한다.

    0번(최위험 구간)을 기준 범주(Reference)로 두면, 나머지 구간의 계수는 "최위험 구간 대비 로짓 차이"가 되고 안전한 구간일수록 **음수**가 된다. 이때 구간 번호는 숫자로 넣는 것이 아니라 **범주형으로 선언해 더미로 전개**한다. 번호를 숫자 그대로 넣으면 "0→1 차이 = 1→2 차이"라는 근거 없는 등간격 가정이 생긴다. WoE/IV는 구간화 품질 평가와 변수 선별에 쓰인다.

### 핵심 차이 비교

| 비교 항목 | 방식 ① WoE 직접 투입 | 방식 ② 더미 변수 방식 |
|-----------|---------------------|---------------------|
| **입력 형태** | WoE 수치 → 연속형 | 구간 번호 → 범주형 더미 |
| **변수당 계수 수** | 1개 (\(\beta_j\)) | (구간수 − 1)개 (\(\gamma_{jb}\)) |
| **자유도 소모** | 변수당 1 | 변수당 (구간수 − 1) |
| **모형 가정** | 로짓이 WoE에 **선형**(구간 간 상대 간격을 단변량 WoE대로 유지) | 구간별 효과를 각각 추정(구간 내 동질성만 가정) |
| **단조성** | 수학적 필수 조건은 아님. 업무 해석·규제 요건으로 별도 점검 | 결과 계수가 비단조로 나올 수 있어 사후 점검 필요 |
| **Stepwise 검정 단위** | 변수 단위, \(\chi^2(1)\) | 변수(그룹) 단위, \(\chi^2\)(구간수−1) |
| **과적합 위험** | 낮음 | 구간 수가 많을수록 증가 |
| **기준점(0점) 구조** | 자연 기준점 없음 → 사후 평행이동 | 기준 범주 \([0,\dots,0]\) → 자동 설정 |
| **WoE 활용** | 회귀 입력값으로 직접 사용 | 구간화 품질 평가·변수 선별에 사용 |

!!! info "WoE 방식의 가정은 '단조성'이 아니라 '선형성'이다"
    WoE 치환은 구간 패턴이 U자형이어도 각 구간의 위험을 그대로 숫자로 바꾼다. WoE 값의 크기 순서가 곧 위험 순서이므로, 원 변수가 비단조여도 WoE에 대한 로짓은 단조다. WoE 방식이 실제로 가정하는 것은 "다변량에서도 구간 간 로짓 차이가 단변량 WoE 차이에 **비례**한다"(계수 하나로 스케일만 조정)는 **선형성**이다. 단조성은 점수를 설명하기 위한 업무·규제 요건으로 따로 점검한다.

!!! info "기준점(0점)이란?"
    스코어카드에서 **부분점수 = 0**이 되는 구간을 기준점이라 한다. 두 방식의 기준점 설정 원리가 다르다.

    **더미 변수 방식** — 구간이 {0, 1, 2}일 때 0번을 기준 범주(Reference)로 지정한다. 기준 범주의 더미 벡터는 \([0, 0]\)(모든 더미가 0)이므로 이 구간의 효과는 절편 \(\beta_0\)에 흡수된다. 나머지 구간의 계수 \(\gamma_{jb}\)는 "기준 대비 로짓 차이"가 되어 자연스럽게 기준점이 생긴다.

    **WoE 직접 투입** — 연속형 수치를 그대로 넣으므로 자연 기준점이 없다(WoE = 0인 지점은 "모집단 평균 위험"이다). 스코어카드 변환 후 원하는 구간의 WoE만큼 전체를 빼는 **평행이동**으로 사후적으로 기준점을 만든다([WoE 직접 투입](woe-entry.md)의 식 (3)).
