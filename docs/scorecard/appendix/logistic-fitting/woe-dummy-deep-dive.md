# 심층 비교 — 사상 차이와 수치 예시

> 같은 로지스틱 회귀라도 WoE 방식과 더미 방식은 **근본적으로 다른 사상(思想)** 으로 작동한다.
> 이 문서는 두 방식의 end-to-end 스코어카드 구축 과정을 수치 예시로 비교하고,
> 기준점(reference point) 이동이 예측을 바꾸지 않는다는 것과 변수 중요도를 읽는 법을 정리한다.
>
> 두 방식의 수리적 구조, 기준점 해석, Stepwise 검정은 본 부록의 [두 방식 비교](index.md), [1. WoE 직접 투입](woe-entry.md), [2. 더미 변수 방식](dummy-entry.md)을 참조한다. 부호는 [부록 공통 규약](../index.md)을 따른다: Bad logit 적합, WoE 계수 정상 부호 \(\beta<0\), 최위험 기준 더미 계수는 안전할수록 \(\gamma<0\), 배점 \(= -B\times\)계수\(\times\)입력.

## 1. 근본적 사상 차이: 단변량 고정 vs 다변량 자유 추정

같은 로지스틱 회귀를 쓰더라도, 두 방식은 **"구간 간 효과를 누가 결정하는가"** 가 다르다.

### 1.1 WoE 방식 — 단변량 패턴을 고정하고, β로 스케일링만

WoE 방식에서는 단변량 분석에서 계산한 구간 간 상대 크기가 **다변량 회귀에서도 그대로 유지**된다.

$$\text{logit}(p_i) = \beta_0 + \beta_j \cdot \text{WoE}_{ij} + \cdots$$

변수 \(j\)의 각 구간이 Bad 로짓에 기여하는 값:

| 구간 | 기여값 |
|------|-------|
| bin 1 | \(\beta_j \times (-0.40)\) |
| bin 2 | \(\beta_j \times (+0.15)\) |
| bin 3 | \(\beta_j \times (+0.55)\) |

\(\beta_j\)는 변수 전체를 **균일하게 스케일링**할 뿐이다. 구간 간 차이의 비율(예: bin 1→2 차이 : bin 2→3 차이 = 0.55 : 0.40)은 **단변량에서 정해진 그대로** 변하지 않는다.

**의미:** 단변량 WoE가 "연소득이 높을수록 우량"이라고 말하면, \(\beta_j\)가 정상 부호(음수)인 한 다변량에서도 그 순서는 깨지지 않는다. \(\beta_j\)는 패턴의 **강도**만 조절한다.

### 1.2 더미 방식 — 다변량에서 구간별 효과를 자유롭게 재추정

더미 방식에서는 각 구간이 **별도의 계수**를 갖는다.

$$\text{logit}(p_i) = \beta_0 + \gamma_{j1} \cdot D_1 + \gamma_{j2} \cdot D_2 + \cdots$$

| 구간 | 기여값 |
|------|-------|
| bin 0 (기준) | \(0\) |
| bin 1 | \(\gamma_{j1}\) (자유 추정) |
| bin 2 | \(\gamma_{j2}\) (자유 추정) |

\(\gamma_{j1}\)과 \(\gamma_{j2}\)는 서로 제약 없이 각각 추정된다. 다른 변수를 통제한 뒤 구간별 효과가 **개별적으로 조정**된다.

**의미:** 단변량에서는 단조였던 패턴이, 다른 변수를 통제하고 나면 **비단조로 바뀔 수 있다.**

### 1.3 차이가 드러나는 구체적 상황

연소득 변수의 단변량 WoE가 다음과 같다고 하자.

| 구간 | 단변량 WoE | 해석 |
|------|-----------|------|
| ~2천만 | −0.40 | 불량 쪽 |
| 2천~5천만 | +0.15 | 약간 우량 |
| 5천만~ | +0.55 | 우량 |

단변량에서는 깔끔한 단조 패턴이다. 그런데 중간 소득 구간에 **부채비율이 낮은 차주가 몰려 있다**고 하자. 그러면 중간 소득 구간의 단변량 우량함 중 상당 부분은 사실 "낮은 부채비율" 덕분이다. 부채비율을 함께 넣으면 그 몫이 부채비율 변수로 넘어가므로, 중간 소득 구간 자체의 효과는 작아진다.

두 방식의 결과를 **같은 기준(~2천만 구간 = 0)** 으로 놓고 비교한다. WoE 방식은 \(\beta = -0.80\)으로 가정한다.

| 구간 | WoE 방식: \(\beta(\text{WoE}_b - \text{WoE}_{\text{기준}})\) | 더미 방식: \(\gamma_b\) (기준 ~2천만) |
|------|-------------------------|--------------------------|
| ~2천만 | 0 (기준) | 0 (기준) |
| 2천~5천만 | \(-0.80 \times (0.15 + 0.40) = -0.44\) | \(\gamma_1 = +0.05\) |
| 5천만~ | \(-0.80 \times (0.55 + 0.40) = -0.76\) | \(\gamma_2 = -0.60\) |

- **WoE 방식:** 단변량 비율이 고정되므로 0 → −0.44 → −0.76으로 단조 감소(소득↑ → 더 안전)가 유지된다.
- **더미 방식:** 2천~5천만 구간의 로짓 차이가 +0.05로, 부채비율을 통제하면 **최저 소득 구간과 비슷하거나 약간 더 위험**하다는 추정이다. 0 → +0.05 → −0.60은 **비단조**다.

어느 쪽이 "맞는가"는 데이터만으로 정할 수 없다. 더미 방식의 +0.05가 유의하지 않다면 두 구간을 합치는 것이 자연스럽고([Stepwise 3.3절](stepwise.md)), 유의하다면 소득 구간 설계나 부채비율과의 교호작용을 다시 봐야 한다. 어느 경우든 점수표에서 "중간 소득이 저소득보다 감점"은 설명하기 어렵다.

### 1.4 정리: 같은 로지스틱, 다른 사상

| 관점 | WoE 방식 | 더미 방식 |
|------|---------|----------|
| **구간 간 패턴 결정자** | 단변량 분석 (사전 고정) | 다변량 회귀 (사후 추정) |
| **다변량에서 계수의 역할** | 변수 전체의 스케일 조절 (\(\beta\) 1개) | 각 구간의 효과를 따로 추정 |
| **단조성** | \(\beta\)가 정상 부호인 한 단변량 순서가 그대로 유지 | 비단조 패턴 허용(사후 점검 필요) |
| **자유도** | 변수당 1개 | 변수당 (구간 수 − 1)개 |
| **과적합 위험** | 낮음 (자유도 적음) | 상대적으로 높음 |
| **성격** | 보수적·안정적 | 유연·민감 |

WoE 방식의 "단변량 패턴 고정"은 약점이 아니라 **의도적 제약**이다. 신용평가에서는 단조성이 업무·규제 요건인 경우가 많고(소득이 높은데 점수가 낮으면 설명이 안 됨), 자유도를 줄여 과적합을 억제하는 **정규화 효과**가 있다.

반면 더미 방식은 다변량 관계를 구간 수준에서 포착하므로 단변량에서 놓친 패턴을 잡아낼 수 있다. 대신 모수가 많아지므로, 구간 수를 줄이거나 비유의 구간을 합치는 방식으로 자유도를 관리하는 것이 중요하다.

## 2. End-to-End 스코어카드 구축: WoE 방식

### 2.1 전체 흐름

```
① Binning → ② WoE 계산 → ③ WoE 치환 → ④ 다변량 로지스틱 회귀(Bad logit)
→ ⑤ β 추정 → ⑥ PDO/Anchor 설정 → ⑦ 배점 변환(상수 배분 포함) → ⑧ 스코어카드 완성
```

### 2.2 수치 예시: 5개 변수

**① Binning & ② WoE 계산** — 각 변수를 구간화하고 단변량 WoE를 산출한다.

| 변수 | 구간 | WoE |
|------|------|-----|
| **연소득** | ~2천만 | −0.40 |
| | 2천~5천만 | +0.15 |
| | 5천만~ | +0.55 |
| **부채비율** | ~30% | +0.50 |
| | 30~60% | +0.10 |
| | 60%~ | −0.45 |
| **연체이력** | 없음 | +0.60 |
| | 1회 | −0.20 |
| | 2회+ | −0.70 |
| **근속연수** | ~1년 | −0.30 |
| | 1~5년 | +0.05 |
| | 5년~ | +0.40 |
| **카드수** | 1~2개 | +0.25 |
| | 3~5개 | +0.10 |
| | 6개~ | −0.35 |

**③ WoE 치환** — 원본 데이터의 각 관측치를 해당 구간의 WoE 값으로 바꾼다.

| 고객 | 연소득(원본) | 연소득(WoE) | 부채비율(원본) | 부채비율(WoE) | ... |
|------|-----------|------------|-------------|-------------|-----|
| A | 6,000만 | +0.55 | 25% | +0.50 | ... |
| B | 1,500만 | −0.40 | 70% | −0.45 | ... |

변수당 컬럼 1개. 5개 변수면 5개 컬럼만으로 회귀에 투입한다.

**④ 다변량 로지스틱 회귀(Bad logit)** — 5개 WoE 컬럼으로 회귀를 적합한다.

$$\text{logit}(p_i) = \beta_0 + \beta_1 \text{WoE}_{\text{연소득}} + \beta_2 \text{WoE}_{\text{부채비율}} + \beta_3 \text{WoE}_{\text{연체}} + \beta_4 \text{WoE}_{\text{근속}} + \beta_5 \text{WoE}_{\text{카드}}$$

**⑤ β 추정 결과** (가상 예시, 모집단 불량률 약 5%):

| 파라미터 | 추정값 | p-value |
|---------|-------|---------|
| \(\beta_0\) (절편) | −2.94 | <0.001 |
| \(\beta_1\) (연소득) | −0.85 | <0.001 |
| \(\beta_2\) (부채비율) | −0.92 | <0.001 |
| \(\beta_3\) (연체이력) | −0.95 | <0.001 |
| \(\beta_4\) (근속연수) | −0.65 | 0.003 |
| \(\beta_5\) (카드수) | −0.70 | 0.008 |

- 모든 \(\beta_j\)가 음수(정상 부호)이고 \(|\beta_j| < 1\)이다. 다변량에서 변수 간 겹치는 정보만큼 단변량 계수(−1)보다 작아진 것이다.
- 절편 \(\beta_0 \approx \ln(N_B/N_G)\)이다. 모든 WoE가 0(평균 위험)인 차주의 Bad 로짓이므로 모집단 불량률 5%면 \(\ln(5/95) = -2.94\) 근처가 된다.

**⑥ PDO/Anchor 설정**

- Anchor: Good Odds 1:1에서 600점(Offset = Anchor가 되어 계산이 단순해지므로 이 예시에서만 쓴다. 본문 [Part 5](../../part5_scorecard/scorecard-and-rating.md)는 평균 위험 근처인 50:1을 기준으로 하며, 1:1을 기준으로 두지 않는 이유도 거기서 설명한다)
- PDO = 20 → \(B = 20 / \ln 2 \approx 28.85\)
- 총점 \(= 600 + B \cdot \ln(\text{Good Odds}) = 600 - B \cdot \text{logit}_{\text{Bad}}\)

**⑦ 배점 변환**

총점을 변수별로 나누면 각 구간의 배점은 다음과 같다(절편 몫은 변수 수 \(k=5\)로 균등 배분).

$$\text{Points}_{j,b} = -B \cdot \beta_j \cdot \text{WoE}_{j,b} - \frac{B \cdot \beta_0}{k}$$

절편 배분: \(-28.85 \times (-2.94) / 5 = +17.0\)

| 변수 | 구간 | WoE | \(-B \cdot \beta_j \cdot \text{WoE}\) | 절편 배분 | **배점** |
|------|------|-----|-------------------------------|----------|------------|
| **연소득** | ~2천만 | −0.40 | \(-28.85 \times (-0.85) \times (-0.40) = -9.8\) | +17.0 | **+7.2** |
| | 2천~5천만 | +0.15 | \(-28.85 \times (-0.85) \times 0.15 = +3.7\) | +17.0 | **+20.6** |
| | 5천만~ | +0.55 | \(-28.85 \times (-0.85) \times 0.55 = +13.5\) | +17.0 | **+30.5** |
| **부채비율** | ~30% | +0.50 | \(+13.3\) | +17.0 | **+30.2** |
| | 30~60% | +0.10 | \(+2.7\) | +17.0 | **+19.6** |
| | 60%~ | −0.45 | \(-11.9\) | +17.0 | **+5.0** |
| **연체이력** | 없음 | +0.60 | \(+16.4\) | +17.0 | **+33.4** |
| | 1회 | −0.20 | \(-5.5\) | +17.0 | **+11.5** |
| | 2회+ | −0.70 | \(-19.2\) | +17.0 | **−2.2** |
| **근속연수** | ~1년 | −0.30 | \(-5.6\) | +17.0 | **+11.3** |
| | 1~5년 | +0.05 | \(+0.9\) | +17.0 | **+17.9** |
| | 5년~ | +0.40 | \(+7.5\) | +17.0 | **+24.5** |
| **카드수** | 1~2개 | +0.25 | \(+5.0\) | +17.0 | **+22.0** |
| | 3~5개 | +0.10 | \(+2.0\) | +17.0 | **+19.0** |
| | 6개~ | −0.35 | \(-7.1\) | +17.0 | **+9.9** |

WoE > 0인 우량 구간은 \(-B\beta\,\text{WoE} > 0\)이 되어 가점, WoE < 0인 불량 구간은 감점이다.

**⑧ 검증: 고객 A의 점수**

고객 A: 연소득 5천만~, 부채비율 ~30%, 연체 없음, 근속 5년~, 카드 1~2개

$$\text{Score}_A = 600 + 30.5 + 30.2 + 33.4 + 24.5 + 22.0 = \mathbf{740.6}$$

검산: 고객 A의 Bad 로짓은 \(-2.94 + (-0.85)(0.55) + (-0.92)(0.50) + (-0.95)(0.60) + (-0.65)(0.40) + (-0.70)(0.25) = -4.87\)이므로 \(600 - 28.85 \times (-4.87) = 740.6\)으로 같다. 이 차주의 PD는 약 0.76%다.

## 3. End-to-End 스코어카드 구축: 더미 방식

### 3.1 전체 흐름

```
① Binning → ② 구간 번호 코딩 → ③ 더미 변수 생성 (기준 범주 지정)
→ ④ 다변량 로지스틱 회귀(Bad logit) → ⑤ 구간별 γ 추정 → ⑥ 배점 변환 → ⑦ 스코어카드 완성
```

### 3.2 수치 예시: 같은 5개 변수

**① Binning** — WoE 방식과 같은 구간화를 쓴다.

**② 구간 번호 코딩** — 각 구간에 정수 번호를 부여한다. 여기서는 위험도 순으로 최위험 구간을 0번(기준)으로 둔다.

| 변수 | 구간 | 코드 | 단변량 WoE (참고용) |
|------|------|------|-------------------|
| **연소득** | ~2천만 | 0 (기준) | −0.40 |
| | 2천~5천만 | 1 | +0.15 |
| | 5천만~ | 2 | +0.55 |
| **부채비율** | 60%~ | 0 (기준) | −0.45 |
| | 30~60% | 1 | +0.10 |
| | ~30% | 2 | +0.50 |
| **연체이력** | 2회+ | 0 (기준) | −0.70 |
| | 1회 | 1 | −0.20 |
| | 없음 | 2 | +0.60 |
| **근속연수** | ~1년 | 0 (기준) | −0.30 |
| | 1~5년 | 1 | +0.05 |
| | 5년~ | 2 | +0.40 |
| **카드수** | 6개~ | 0 (기준) | −0.35 |
| | 3~5개 | 1 | +0.10 |
| | 1~2개 | 2 | +0.25 |

WoE/IV는 구간화 품질 평가와 변수 선별에 쓰고, 회귀에는 구간 번호를 **범주형으로 선언해 더미로 전개**해 투입한다.

**③ 더미 변수 생성** — 기준 범주(0)를 제외하고 (구간 수 − 1)개의 더미를 만든다.

| 고객 | 연소득 원본 | 연소득_D1 | 연소득_D2 | 부채비율 원본 | 부채비율_D1 | 부채비율_D2 | ... |
|------|-----------|----------|----------|-----------|-----------|-----------|-----|
| A | 6,000만 (코드2) | 0 | 1 | 25% (코드2) | 0 | 1 | ... |
| B | 1,500만 (코드0) | 0 | 0 | 70% (코드0) | 0 | 0 | ... |

5개 변수 × 2개 더미 = **10개 컬럼**으로 회귀에 투입한다.

**④ 다변량 로지스틱 회귀(Bad logit)**

$$\text{logit}(p_i) = \beta_0 + \sum_{j=1}^{5} \sum_{b=1}^{2} \gamma_{jb} \cdot D_{jb}$$

**⑤ 구간별 γ 추정 결과** (가상 예시):

| 변수 | 구간 | 더미 | \(\gamma\) 추정값 | p-value |
|------|------|------|---------------|---------|
| | | | \(\beta_0 = -1.10\) | <0.001 |
| **연소득** | ~2천만 | (기준) | 0 (고정) | — |
| | 2천~5천만 | D1 | −0.38 | 0.021 |
| | 5천만~ | D2 | −0.72 | <0.001 |

- 각 \(\gamma_{jb}\)는 **"기준 구간(최위험) 대비 해당 구간의 Bad 로짓 감소량"** 이다. 모두 음수이고, 같은 변수 안에서 안전한 구간일수록 더 작다(정상).
- 절편 \(\beta_0 = -1.10\)은 다섯 변수 모두 최위험 구간인 차주의 Bad 로짓이다(PD 약 25%).

**핵심:** WoE 방식에서는 \(\beta_j\)가 1개이므로 구간 간 비율이 고정되지만, 더미 방식에서는 \(\gamma_{j1}\)과 \(\gamma_{j2}\)가 **각각 추정**되므로 구간 간 비율이 다변량에서 결정된다.

**⑥ 배점 변환**

- 기준 구간: 배점 = 절편 배분값
- 나머지 구간: 배점 = 절편 배분값 \(- B \times \gamma_{jb}\)

## 4. 기준점 이동의 수학적 동치 증명

WoE와 더미가 "사상이 다르다"는 것과 별개로, **같은 모형 안에서** 기준점을 옮기는 것은 예측값에 영향을 주지 않는다.

### 4.1 단일 변수 케이스

변수 X에 3개 구간이 있고, WoE 값이 각각 \(w_1, w_2, w_3\)이라 하자. bin 2를 기준점(0점)으로 삼고 싶다면 \(c = w_2\)를 뺀다.

$$\beta_0 + \beta_1 w_i = (\beta_0 + \beta_1 c) + \beta_1 (w_i - c)$$

| bin | 원래 WoE | 조정 후 (\(w_i - c\)) |
|-----|---------|-------------------|
| bin 1 | \(w_1\) | \(w_1 - w_2\) |
| bin 2 | \(w_2\) | \(0\) (기준) |
| bin 3 | \(w_3\) | \(w_3 - w_2\) |

\(\beta_1 c\)는 절편에 흡수 → **예측값 불변**. \(\beta_1\) 자체도 바뀌지 않는다.

### 4.2 다변량 케이스 (변수 5개)

변수 \(X_1, \dots, X_5\)이고, 각각의 기준 구간 WoE가 \(c_1, \dots, c_5\)일 때:

$$\beta_0 + \sum_{j=1}^{5} \beta_j \text{WoE}_{X_j} = \underbrace{\left(\beta_0 + \sum_{j=1}^{5} \beta_j c_j\right)}_{\beta_0'} + \sum_{j=1}^{5} \beta_j \underbrace{(\text{WoE}_{X_j} - c_j)}_{\text{WoE}'_{X_j}}$$

핵심:

- 각 변수의 기준점 이동은 **독립적**이다. 한 변수의 \(c_j\)를 바꿔도 다른 변수의 \(\beta_k\)에 영향이 없다.
- 모든 이동량은 **\(\beta_j c_j\)의 합**으로 절편 하나에 흡수된다(\(c_j\)의 단순 합이 아니다).
- \(\beta_j\) 값 자체는 변하지 않는다.

### 4.3 수치 검증

2절의 5개 변수 예시(\(\beta_0 = -2.94\), \(\beta = (-0.85, -0.92, -0.95, -0.65, -0.70)\))에서, 각 변수의 중간 구간을 기준으로 잡아 본다.

| 변수 | 기준 구간 | \(c_j\) | \(\beta_j c_j\) |
|------|----------|-------|------|
| 연소득 | 2천~5천만 | +0.15 | −0.1275 |
| 부채비율 | 30~60% | +0.10 | −0.0920 |
| 연체이력 | 1회 | −0.20 | +0.1900 |
| 근속연수 | 1~5년 | +0.05 | −0.0325 |
| 카드수 | 3~5개 | +0.10 | −0.0700 |
| **합계** | | | **−0.1320** |

**조정 결과:**

| 변수 | 구간 | 원래 WoE | \(-c_j\) | **조정 후** |
|------|------|---------|--------|------------|
| **연소득** | ~2천만 | −0.40 | −0.15 | **−0.55** |
| | 2천~5천만 | +0.15 | −0.15 | **0.00** ← 기준 |
| | 5천만~ | +0.55 | −0.15 | **+0.40** |
| **부채비율** | ~30% | +0.50 | −0.10 | **+0.40** |
| | 30~60% | +0.10 | −0.10 | **0.00** ← 기준 |
| | 60%~ | −0.45 | −0.10 | **−0.55** |
| **연체이력** | 없음 | +0.60 | +0.20 | **+0.80** |
| | 1회 | −0.20 | +0.20 | **0.00** ← 기준 |
| | 2회+ | −0.70 | +0.20 | **−0.50** |
| **근속연수** | ~1년 | −0.30 | −0.05 | **−0.35** |
| | 1~5년 | +0.05 | −0.05 | **0.00** ← 기준 |
| | 5년~ | +0.40 | −0.05 | **+0.35** |
| **카드수** | 1~2개 | +0.25 | −0.10 | **+0.15** |
| | 3~5개 | +0.10 | −0.10 | **0.00** ← 기준 |
| | 6개~ | −0.35 | −0.10 | **−0.45** |

**절편 흡수:**

$$\beta_0' = \beta_0 + \sum_j \beta_j c_j = -2.94 + (-0.132) = -3.072$$

**같은 고객 검증** (연소득 5천만~, 부채비율 60%~, 연체 없음, 근속 1~5년, 카드 3~5개):

- 원래: \(-2.94 + (-0.85)(0.55) + (-0.92)(-0.45) + (-0.95)(0.60) + (-0.65)(0.05) + (-0.70)(0.10)\)
  \(= -2.94 - 0.4675 + 0.414 - 0.570 - 0.0325 - 0.070 = \mathbf{-3.666}\)
- 조정 후: \(-3.072 + (-0.85)(0.40) + (-0.92)(-0.55) + (-0.95)(0.80) + 0 + 0\)
  \(= -3.072 - 0.340 + 0.506 - 0.760 = \mathbf{-3.666}\)

두 로짓이 정확히 같다. 기준점 이동은 예측값을 바꾸지 않는다.

## 5. 변수 중요도: 기준점 이동에 불변

### 5.1 핵심 원리

점수표에서 변수의 영향력을 볼 때는 개별 구간 배점의 절대값이 아니라 **변수 안 배점의 범위(max − min)** 를 본다. 기준점 이동은 상수를 더하는 것이므로 max와 min이 같은 양만큼 움직여 **범위가 불변**이다.

### 5.2 WoE 범위 비교

| 변수 | 원래 WoE 범위 | range | 조정 후 범위 | range |
|------|-------------|-------|------------|-------|
| 연체이력 | +0.60 ~ −0.70 | **1.30** | +0.80 ~ −0.50 | **1.30** |
| 연소득 | +0.55 ~ −0.40 | **0.95** | +0.40 ~ −0.55 | **0.95** |
| 부채비율 | +0.50 ~ −0.45 | **0.95** | +0.40 ~ −0.55 | **0.95** |
| 근속연수 | +0.40 ~ −0.30 | **0.70** | +0.35 ~ −0.35 | **0.70** |
| 카드수 | +0.25 ~ −0.35 | **0.60** | +0.15 ~ −0.45 | **0.60** |

WoE range 순위(연체이력 > 연소득 = 부채비율 > 근속연수 > 카드수)는 **기준점과 무관하게 불변**이다. 다만 WoE range는 단변량 정보일 뿐이고, 다변량 모형에서의 영향력은 계수까지 곱한 배점 범위로 본다.

### 5.3 배점 범위

배점 범위 \(= |\beta_j| \times B \times \text{WoE range}\)이다.

| 변수 | WoE range | \(\beta_j\) | **배점 범위** |
|------|-----------|----------|---------------------------|
| 연체이력 | 1.30 | −0.95 | \(0.95 \times 28.85 \times 1.30 = \mathbf{35.6}\) |
| 부채비율 | 0.95 | −0.92 | \(0.92 \times 28.85 \times 0.95 = \mathbf{25.2}\) |
| 연소득 | 0.95 | −0.85 | \(0.85 \times 28.85 \times 0.95 = \mathbf{23.3}\) |
| 근속연수 | 0.70 | −0.65 | \(0.65 \times 28.85 \times 0.70 = \mathbf{13.1}\) |
| 카드수 | 0.60 | −0.70 | \(0.70 \times 28.85 \times 0.60 = \mathbf{12.1}\) |

WoE range가 같던 연소득과 부채비율이 계수 차이 때문에 배점 범위에서는 부채비율 > 연소득으로 갈린다. 기준점을 어디로 잡든 이 배점 범위는 변하지 않는다.

!!! warning "배점 범위의 한계"
    배점 범위는 **양 끝 구간**만 본다. 극단 구간에 차주가 1%밖에 없다면, 범위가 커도 실제 점수 분포에 미치는 영향은 작다. 변수의 실질적 기여를 보려면 범위와 함께 **IV**나 **배점의 분산(구간 비중 가중)** 을 같이 보고, 극단 구간의 표본 비중을 확인한다.

### 5.4 흔한 오해: "최대 절대값 = 중요도"?

| 변수 | 배점 범위 | max 절대값 | range |
|------|---------|-----------|-------|
| 변수A | −10 ~ +10 | 10 | **20** |
| 변수B | −30 ~ +10 | 30 | **40** |

max 절대값만 보면 변수B가 3배 중요해 보이지만, 실제 영향력 차이는 2배(range 기준)다. 가장 나쁜 구간을 0점으로 맞추면:

| 변수 | 보정 후 범위 | range |
|------|------------|-------|
| 변수A | 0 ~ 20 | **20** |
| 변수B | 0 ~ 40 | **40** |

"보정 때문에 중요도가 바뀌었다"가 아니라, **원래부터 변수B의 영향 범위가 2배였는데 보정 후 더 눈에 잘 띄게 된 것**뿐이다.

## 6. 절편 배분과 기준점 설정은 다른 조작이다

### 6.1 절편 배분 = 상수를 나눠 담는 표시 방식

2절 ⑦에서 쓴 절편 배분

$$-\frac{B \cdot \beta_0}{k}$$

은 **모든 변수의 모든 구간에 같은 값**을 더한다. 이것은 총점의 상수항을 변수별로 쪼개 담아 "변수 배점의 합 = 총점"이 되게 하는 **표시 방식**일 뿐, 어떤 구간도 0점으로 만들지 않는다. 실제로 2절 예시에서 0점인 구간은 하나도 없다.

### 6.2 기준점 설정 = 특정 구간을 0점으로 맞추는 평행이동

반면 [WoE 직접 투입 1.3절](woe-entry.md)의 평행이동은 변수마다 **기준 구간의 WoE를 빼서** 그 구간을 0점으로 만들고, 빠진 만큼을 상수항에서 보정한다. 4절의 증명이 이 조작에 해당한다.

두 조작은 모두 예측값을 바꾸지 않지만 목적이 다르다.

| 조작 | 무엇을 바꾸나 | 결과 점수표의 모습 |
|---|---|---|
| 절편 배분 | 상수항을 변수 수로 나눠 각 구간에 똑같이 더함 | 0점 구간이 없음. "배점 합 = 총점" |
| 기준점 평행이동 | 변수별 기준 구간이 0점이 되도록 이동, 상수항 보정 | 변수마다 0점 구간이 하나씩 생김 |
| 둘 다 적용 | 평행이동 후 남은 상수항을 다시 배분 | 기준 구간 = 배분값, 나머지 = 배분값 + 차이 |

### 6.3 두 방식의 기준점 처리 시점 비교

| 단계 | 더미 방식 | WoE 방식 |
|------|----------|----------|
| **인코딩** | 기준 범주 명시 선택 | WoE = 0이 "모집단 평균 위험"에 해당(실제 구간과는 대개 불일치) |
| **회귀** | 기준 범주 대비 계수 추정 | WoE 값에 대한 계수 추정 |
| **배점 변환** | 기준 범주 = 0점(배분 전) | 기준 구간을 원하면 평행이동으로 설정 |
| **상수항** | 절편 배분 여부는 표시 선택 | 절편 배분 여부는 표시 선택 |

## 7. 결론

1. **같은 로지스틱 회귀라도 사상이 다르다.** WoE 방식은 단변량 패턴을 고정하고 \(\beta\)(정상 부호 음수)로 스케일링만 하며, 더미 방식은 다변량에서 구간별 효과를 재추정한다. WoE의 패턴 고정은 순서 유지와 과적합 억제라는 의도적 제약이다.

2. **같은 모형 안에서 기준점 이동은 예측값을 바꾸지 않는다.** 이동량 \(\sum_j \beta_j c_j\)는 절편에 흡수되며, 다변량에서도 변수별로 독립적으로 작동한다.

3. **변수의 영향력은 배점 범위(\(|\beta_j| \times B \times\) WoE range)로 보되, 극단 구간의 표본 비중과 IV를 함께 본다.** 범위는 기준점과 무관하다.

4. **절편 배분과 기준점 설정은 다른 조작이다.** 절편 배분은 상수를 나눠 담는 표시 방식이고, 기준점 설정은 특정 구간을 0점으로 맞추는 평행이동이다. 둘 다 예측에는 영향이 없다.
