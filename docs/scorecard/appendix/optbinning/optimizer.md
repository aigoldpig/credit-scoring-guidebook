# 최적화 엔진 — 구간 병합을 이진 최적화로 푼다

## 1.1 왜 "최적화"인가

전통적 Coarse Classing은 Fine Bin을 보면서 비슷한 구간을 **하나씩** 합친다(ChiMerge 등). 이런 탐욕적(greedy) 병합은 매 단계에서 가장 좋아 보이는 쌍을 합칠 뿐, 앞에서 내린 병합을 되돌리지 않는다. 그래서 "단조성을 지키면서 Bin 수는 5개 이하, 각 Bin은 5% 이상"처럼 제약이 여러 개 걸리면, 최종 결과가 가능한 조합 중 최선이라는 보장이 없다.

optbinning은 이 문제를 **"가능한 모든 병합 조합 중, 제약을 만족하면서 IV가 최대인 것"** 을 찾는 수리 최적화 문제로 바꿔 푼다(Navas-Palencia, 2020). 엄밀 Solver는 해를 찾을 뿐 아니라 그 해가 최적임을 상한·하한 비교로 증명하므로, 제약 하에서 **전역 최적(global optimum)** 이 보장된다. 단, 이 최적은 "Pre-binning이 만든 경계 안에서의 최적"이다.

## 1.2 문제 정식화

Pre-binning으로 \(n\)개의 Fine Bin(이하 prebin)이 있다고 하자. prebin \(j\)부터 \(i\)까지(\(j \le i\))를 하나로 합친 구간을 \([j, i]\)라 쓴다.

**결정 변수**: 각 후보 구간 \([j,i]\)마다 이진 변수 \(x_{ij}\)를 둔다. 이 구간이 최종 Bin으로 채택되면 1, 아니면 0이다. 후보 구간은 연속된 prebin만으로 만들므로 **인접성은 변수 정의에 이미 들어 있다**.

**목적함수**: 채택된 구간들의 IV 합을 최대화한다. IV는 구간별 기여의 합이므로, 각 후보 구간의 IV 기여 \(V_{ij}\)를 미리 계산해 두면 목적함수가 선형이 된다.

$$
\max \sum_{j \le i} V_{ij}\, x_{ij}, \qquad V_{ij} = (\%\text{Good}_{[j,i]} - \%\text{Bad}_{[j,i]}) \cdot \text{WoE}_{[j,i]} \tag{1}
$$

**제약식**:

$$
\sum_{j \le r \le i} x_{ij} = 1 \quad (r = 1, \dots, n) \tag{2}
$$

식 (2)는 "모든 prebin \(r\)은 채택된 구간 중 **정확히 하나**에 속한다"는 뜻이다. 이 제약만으로 해는 항상 연속 구간들로 이뤄진 분할(partition)이 된다.

| 제약 | 수학적 표현(개념) | 대응 옵션 |
|------|-----------|-------------|
| 유일 할당 | 식 (2) | — |
| Bin 수 | \(n_{\min} \le \sum x_{ij} \le n_{\max}\) | 최소/최대 Bin 수 |
| 최소·최대 표본 | 표본 비중이 기준 밖인 후보 구간은 \(x_{ij}=0\)으로 고정 | 최소/최대 Bin 비중, 최소 Bad·Good 건수 |
| 단조성 | 이웃하는 두 채택 구간 \([k, j-1]\)과 \([j, i]\)의 Event rate 순서가 지정 방향과 어긋나면 동시에 채택할 수 없다: \(x_{j-1,k} + x_{ij} \le 1\) | 단조성 방향(Event rate 기준) |
| 유의성 | 이웃하는 두 채택 구간의 불량률 차이 검정 p-value가 기준을 넘으면 동시 채택 금지 | 최대 p-value |

단조성과 유의성 제약은 위 표처럼 "어긋나는 이웃 쌍 금지"로 이해하면 직관적이다. 원 논문은 같은 내용을 Event rate에 대한 선형 부등식(big-M 형태)으로 더 간결하게 정식화한다.

!!! note "목적함수는 IV만이 아니다"
    기본 목적함수는 IV(Jeffreys divergence)지만, 라이브러리는 Jensen-Shannon, Hellinger, Triangular divergence도 고를 수 있다([공식 문서](https://gnpalencia.org/optbinning/binning_binary.html)). 어느 쪽이든 "구간별 기여의 합"이라는 구조는 같다.

## 1.3 소형 예시 — prebin 5개, 분할 16개

prebin 5개의 경계는 4곳이다. 각 경계를 "유지/삭제" 중 하나로 고르므로 가능한 분할은 \(2^4 = 16\)가지다. 카드 사용률 변수의 가상 prebin(총 10,000건, Bad 900건)으로 16개를 모두 계산하면 다음과 같다.

| prebin | P1 | P2 | P3 | P4 | P5 |
|---|:---:|:---:|:---:|:---:|:---:|
| 건수 | 1,500 | 1,300 | 1,200 | 2,500 | 3,500 |
| Bad | 20 | 70 | 55 | 250 | 505 |
| 불량률 | 1.33% | 5.38% | 4.58% | 10.0% | 14.4% |

P2→P3에서 불량률이 잠깐 내려간다(역전). 사용률이 높을수록 위험하다는 업무 논리상 **Event rate 증가(ascending)** 제약을 건다. 아래 표에서 `·`는 구간 경계를, `+`는 병합을 뜻한다.

| 순위 | 분할 | 구간 불량률 | IV | 단조 증가? |
|:---:|---|---|:---:|:---:|
| 1 | P1 · P2 · P3 · P4 · P5 (병합 없음) | 1.33 / 5.38 / 4.58 / 10.0 / 14.4% | 0.4853 | ✗ |
| 2 | **P1 · P2+P3 · P4 · P5** | 1.33 / 5.00 / 10.0 / 14.4% | **0.4838** | ✓ |
| 3 | P1 · P2 · P3 · P4+P5 | 1.33 / 5.38 / 4.58 / 12.6% | 0.4565 | ✗ |
| 4 | **P1 · P2+P3 · P4+P5** | 1.33 / 5.00 / 12.6% | **0.4550** | ✓ |
| 5 | P1 · P2 · P3+P4 · P5 | 1.33 / 5.38 / 8.24 / 14.4% | 0.4383 | ✓ |
| … | (나머지 10개) | | ≤ 0.4214 | |
| 16 | 전부 병합 | 9.00% | 0 | ✓ |

- **제약이 없으면** 병합하지 않는 것(1위)이 항상 IV 최대다. 구간을 합치면 IV는 줄거나 같을 뿐 늘지 않기 때문이다. 즉 IV 최대화는 제약이 있어야 의미가 생긴다.
- **단조 제약만** 걸면 최적해는 역전 쌍 P2+P3만 합친 2위다.
- **단조 제약 + 최대 Bin 3개**를 걸면 최적해는 4위(P1 · P2+P3 · P4+P5)로 바뀐다.

prebin이 20개면 후보 분할은 \(2^{19} = 524{,}288\)개다. 이 정도는 전수 탐색도 가능하지만 prebin 수가 늘면 \(2^{n-1}\)로 폭증하고, 실제 문제는 여러 제약이 얽혀 있다. Solver는 제약 전파와 분기한정(branch-and-bound)으로 대부분의 조합을 계산하지 않고 잘라내면서도 최적성을 증명한다.

<div class="source-ref">예시 수치는 가상 데이터이며, 16개 분할의 IV는 직접 전수 계산한 값이다.</div>

## 1.4 Solver 선택

| Solver 옵션 | 내부 엔진 | 원리 |
|--------|----------|------|
| CP (기본값) | Google OR-Tools CP-SAT | 제약 전파(constraint propagation) + 탐색 |
| MIP | Google OR-Tools BOP 또는 COIN-OR CBC | 분기한정(branch-and-bound) |
| LS | LocalSolver(상용) | 국소 탐색 기반 — 대규모 문제용 |

<div class="source-ref">출처: <a href="https://gnpalencia.org/optbinning/binning_binary.html" target="_blank">optbinning 공식 문서 — OptimalBinning</a></div>

!!! note "실무 권장"
    특별한 이유가 없으면 기본값 CP를 쓴다. CP와 MIP는 같은 문제를 풀므로 최적 IV 값은 같아야 하며(동률 해가 여럿이면 다른 분할이 나올 수 있다), 차이는 주로 계산 시간이다. prebin이 많아 시간이 오래 걸리면 Solver를 바꾸기보다 단조성 옵션의 휴리스틱 버전을 쓰거나(공식 문서는 prebin 20개 초과에서 "significantly faster"라고 안내한다) prebin 수를 줄이는 쪽이 효과적이다.
