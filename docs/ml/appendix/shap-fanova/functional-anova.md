# 2. Functional ANOVA — 함수의 직교 분해

---

[1절](non-identifiability.md)에서 확인한 것처럼, 제약 없이는 하나의 함수를 무한히 많은 방식으로 분해할 수 있고, 분해마다 해석이 달라진다. 그러면 **제약을 걸어서 분해를 하나로 고정**하면 되지 않을까? Functional ANOVA(fANOVA)가 바로 그것이다 — 수학적 조건을 부과하여 분해를 **유일하게** 결정하는 프레임워크다.

이 절에서는 먼저 "Functional ANOVA"라는 이름의 유래를 짚은 뒤, 분해 공식이 실제로 무엇을 계산하는지 1절의 XOR 예시에 직접 적용해본다. 그런 다음 fANOVA 분해가 갖는 세 가지 성질(Zero Means, Orthogonality, Variance Decomposition)을 확인하고, 마지막으로 이 성질들을 모두 함축하면서 분해를 유일하게 만드는 핵심 조건 — **Integrate-to-Zero** — 를 다룬다.

!!! warning "이 절의 전제 — 변수 독립(product measure)"
    fANOVA의 모든 적분(평균)은 어떤 확률분포 위에서 계산된다. 이 절은 **변수들이 서로 독립인 분포**, 즉 각 변수의 주변분포를 곱한 측도(product measure) \(\mathbb{P}(X_1)\mathbb{P}(X_2)\cdots\mathbb{P}(X_p)\)를 전제로 설명한다. 전통적인 fANOVA(Hoeffding, Sobol)가 이 가정 위에 서 있고, 아래의 깔끔한 성질들 — 특히 분산 분해 — 도 이 가정에서만 그대로 성립한다.

    신용평가 변수처럼 서로 상관이 강한 경우에는 측도를 무엇으로 잡느냐에 따라 분해 결과가 달라지고, 분산 분해에 교차공분산 항이 생긴다. 이 문제는 [부록 B: 변수 상관과 모형 해석](../correlation-interpretation/index.md)에서 따로 다룬다.

## 왜 "ANOVA"인가 — 통계학에서 함수 분해로

fANOVA를 본격적으로 다루기 전에, 이름에 담긴 의미를 짚고 가자.

### 통계학의 ANOVA

ANOVA(Analysis of Variance)는 **데이터의 총 변동을 요인별로 분해**하는 기법이다. 예를 들어, "직급에 따라 소득이 다른가?"를 검정한다고 하자:

$$
\underbrace{\text{소득의 총 변동}}_{\text{SST}} = \underbrace{\text{직급 간 변동}}_{\text{SSB}} + \underbrace{\text{직급 내 변동}}_{\text{SSW}}
$$

SSB(집단 간)가 SSW(집단 내)에 비해 충분히 크면, "직급이 소득에 유의한 영향을 미친다"고 판단한다. 핵심은 **변동을 쪼개서 각 요인의 기여를 정량화**하는 것이다.

2-way ANOVA로 확장하면 요인이 2개(예: 직급 × 성별)가 되고, 총 변동을 "직급 효과 + 성별 효과 + 직급×성별 교호작용 + 잔차"로 분해한다. main effect와 interaction을 분리하는 구조가 여기서 이미 나타난다.

### "Functional"이 붙은 이유

Functional ANOVA는 같은 분해 아이디어를 **함수**에 적용한 것이다:

| | 전통 ANOVA | Functional ANOVA |
|---|---|---|
| **분해 대상** | 데이터의 변동 | **함수**(모형 출력)의 변동 |
| **요인** | 범주형 변수 (직급, 성별) | 모형의 입력 변수 (소득, DTI, ...) |
| **묻는 질문** | "직급이 소득 변동의 몇 %를 설명하는가?" | "소득 변수가 **모형 출력 변동**의 몇 %를 설명하는가?" |
| **교호작용** | 직급×성별 interaction | 소득×DTI interaction |

"Functional"이라는 수식어는, 분해 대상이 데이터 포인트가 아니라 **함수 자체**(모형의 예측 함수 \(\hat{f}\))이기 때문에 붙었다. 이 분해의 수학적 뿌리는 Hoeffding(1948)의 통계량 분해와 Sobol의 민감도 분석으로 거슬러 올라가며, 이후 통계학에서 "functional ANOVA"라는 이름으로 정착했다. Hooker(2004)가 이것을 블랙박스 ML 모형의 해석에 적용하면서 현재의 맥락으로 이어진다.

전통 ANOVA의 핵심이 "이 요인이 유의한가?"를 분산 비율로 판단하는 것이듯, fANOVA의 핵심도 **"이 변수(또는 변수 조합)가 모형 출력 변동의 몇 %를 설명하는가?"**를 정량화하는 것이다. 이것이 아래에서 다룰 Variance Decomposition(식 4)이다.

## 분해의 정의

임의의 함수 \(\hat{f}(\mathbf{x})\)를 **모든 변수 부분집합의 효과 합**으로 분해한다:

$$
\hat{f}(\mathbf{x}) = f_0 + \sum_{i} f_i(x_i) + \sum_{i < j} f_{ij}(x_i, x_j) + \cdots + f_{1,\ldots,p}(x_1, \ldots, x_p)
\tag{1}
$$

여기서 \(f_0\)은 전체 평균(intercept), \(f_i\)는 변수 \(i\)의 주효과, \(f_{ij}\)는 변수 \(i, j\)의 2차 교호작용이다. 변수가 \(p\)개이면 가능한 부분집합이 \(2^p\)개이므로, 최대 \(2^p\)개의 component가 존재한다. 이하 변수 집합 전체를 \([p] = \{1, \ldots, p\}\), 그 부분집합을 \(S\)로 쓴다.

변수가 독립일 때 각 component \(f_S\)는 **재귀적으로** 구할 수 있다 (Hooker, 2004):

$$
f_S(\mathbf{x}_S) = \int \left( \hat{f}(\mathbf{x}) - \sum_{V \subsetneq S} f_V(\mathbf{x}_V) \right) d\mathbb{P}(\mathbf{x}_{-S})
$$

수식이 복잡해 보이지만, 하는 일은 두 단계다: **(1)** \(S\)에 포함되지 않는 변수들(\(\mathbf{x}_{-S}\))을 그 **주변분포** \(\mathbb{P}(\mathbf{x}_{-S})\)에 따라 적분(평균)해서 없앤다. **(2)** 이미 구해진 하위 component(\(f_V\), \(V \subsetneq S\))를 뺀다. "하위 component"란 현재 구하려는 것보다 **더 적은 수의 변수**로 설명되는 효과를 말한다. 예를 들어 \(f_{12}\)(2변수 효과)의 하위 component는 \(f_0\), \(f_1\), \(f_2\)(0~1변수 효과)다.

이 절차를 가장 단순한 것부터 차례로 풀면, 각 component가 무엇인지 명확해진다:

| Component | 수식 (독립 가정) | 직관 |
|-----------|------|------|
| Intercept | \(f_0 = \mathbb{E}[\hat{f}(\mathbf{X})]\) | 전체 평균. 모든 변수를 적분해서 없앤 값 |
| Main effect | \(f_1(x_1) = \mathbb{E}_{\mathbf{X}_{-1}}\big[\hat{f}(x_1, \mathbf{X}_{-1})\big] - f_0\) | \(X_1\)만 \(x_1\)로 고정하고 나머지를 **주변분포**로 평균 낸 뒤, 전체 평균을 빼면 \(X_1\)만의 **순수 효과** |
| 2차 interaction | \(f_{12}(x_1, x_2) = \mathbb{E}_{\mathbf{X}_{-12}}\big[\hat{f}(x_1, x_2, \mathbf{X}_{-12})\big] - f_1 - f_2 - f_0\) | 두 변수를 모두 고정했을 때의 값에서, 이미 설명된 효과(전체 평균 + 각각의 주효과)를 빼면 **두 변수가 동시에 특정 조합일 때만 나타나는 효과**가 남는다 |

변수가 독립이면 "나머지를 주변분포로 평균"한 값은 조건부기대값 \(\mathbb{E}[\hat f(\mathbf{X}) \mid X_1 = x_1]\)과 같다. 그러나 변수가 상관되어 있으면 둘은 다르고, 조건부기대값을 그대로 넣어 위 공식을 계산하면 아래에서 설명할 성질들이 깨진다. 이 함정은 [부록 B 2절](../correlation-interpretation/joint-vs-product.md)에서 수치로 확인한다.

핵심 원리: **나머지 변수를 적분해서 없앤 뒤, 더 적은 수의 변수로 이미 설명된 효과를 빼면, 해당 변수 집합만의 순수 효과가 남는다.** 이 "빼기"가 없으면 main effect와 교호작용이 뒤섞이는데, 그것이 1절에서 본 non-identifiability의 원인이었다.

### XOR 함수로 직접 계산해보기

공식이 실제로 어떻게 작동하는지 확인하는 가장 좋은 방법은 직접 계산해보는 것이다. [1절](non-identifiability.md)에서 네 가지 분해를 보았던 XOR 함수에 fANOVA를 적용하자.

\(X_1, X_2\)가 서로 독립이고 각각 0과 1을 같은 확률로 갖는다고 가정한다 (4가지 입력이 동일 확률 1/4). 이 분포는 product measure이므로 이 절의 전제를 그대로 만족한다.

대상 함수: \(Y(0,0)=0,\; Y(0,1)=1,\; Y(1,0)=1,\; Y(1,1)=0\)

**Intercept — 전체 평균:**

가장 먼저 구하는 것은 \(f_0\)이다. 모든 변수를 적분해서 없앤 값, 즉 \(Y\)의 기대값이다:

$$
f_0 = \mathbb{E}[Y] = \frac{0 + 1 + 1 + 0}{4} = 0.5
$$

**Main effect — 나머지를 평균 내고, 전체 평균을 뺀다:**

\(f_1(x_1)\)을 구하려면, \(X_1\)을 특정 값으로 고정한 상태에서 \(X_2\)에 대해 평균을 내고, 방금 구한 전체 평균 \(f_0\)을 뺀다. \(f_0\)을 빼는 이유는, 전체 평균은 이미 intercept에 담겨 있으므로 main effect에서는 **전체 평균을 초과하는 부분**만 남겨야 하기 때문이다:

$$
f_1(0) = \mathbb{E}_{X_2}[Y(0, X_2)] - f_0 = \frac{Y(0,0) + Y(0,1)}{2} - 0.5 = \frac{0 + 1}{2} - 0.5 = 0
$$

$$
f_1(1) = \mathbb{E}_{X_2}[Y(1, X_2)] - f_0 = \frac{Y(1,0) + Y(1,1)}{2} - 0.5 = \frac{1 + 0}{2} - 0.5 = 0
$$

\(f_2\)도 같은 방식으로 구한다. \(X_2\)를 고정하고 \(X_1\)에 대해 평균을 낸다:

$$
f_2(0) = \mathbb{E}_{X_1}[Y(X_1, 0)] - f_0 = \frac{Y(0,0) + Y(1,0)}{2} - 0.5 = \frac{0 + 1}{2} - 0.5 = 0
$$

$$
f_2(1) = \mathbb{E}_{X_1}[Y(X_1, 1)] - f_0 = \frac{Y(0,1) + Y(1,1)}{2} - 0.5 = \frac{1 + 0}{2} - 0.5 = 0
$$

\(X_1\)이든 \(X_2\)든, 0일 때의 평균 출력과 1일 때의 평균 출력이 동일하다 (둘 다 0.5). 따라서 main effect는 정확히 0이다. 이것은 **XOR이 순수한 교호작용 함수**라는 직관과 일치한다 — 변수 하나만으로는 출력을 예측할 수 없으니까.

**2차 교호작용 — 하위 효과를 모두 빼고 남은 것:**

마지막으로 \(f_{12}\)를 구한다. 원래 함수에서 intercept(\(f_0\))와 main effect(\(f_1, f_2\))로 **이미 설명된 부분**을 빼면, 두 변수가 동시에 특정 조합일 때만 나타나는 순수한 효과가 남는다:

$$
f_{12}(x_1, x_2) = Y(x_1, x_2) - f_0 - f_1(x_1) - f_2(x_2)
$$

왜 빼는가? 빼지 않으면 \(f_{12}\)에 main effect와 intercept가 중복으로 담긴다. 1절의 분해 ①이 정확히 이 경우였다 — \(f_{12}\)가 \(Y\) 자체였고, 그 안에 전체 평균 0.5가 그대로 들어 있었다.

XOR에서는 \(f_1 = f_2 = 0\)이므로, 전체 평균 0.5만 빼면 된다:

| \(f_{12}\) | \(X_2=0\) | \(X_2=1\) |
|---|---|---|
| \(X_1=0\) | \(0 - 0.5 = \mathbf{-0.5}\) | \(1 - 0.5 = \mathbf{+0.5}\) |
| \(X_1=1\) | \(1 - 0.5 = \mathbf{+0.5}\) | \(0 - 0.5 = \mathbf{-0.5}\) |

읽는 법: \(f_{12} = +0.5\)인 칸(서로 다른 조합: 0-1, 1-0)은 평균보다 **높고**, \(f_{12} = -0.5\)인 칸(같은 조합: 0-0, 1-1)은 평균보다 **낮다.** XOR의 "서로 달라야 1"이라는 패턴이 교호작용에 그대로 담겨 있다.

### fANOVA 분해 vs 1절의 네 가지 분해

방금 구한 fANOVA 분해(\(f_0 = 0.5,\; f_1 = f_2 = 0,\; f_{12} = [-0.5, 0.5;\; 0.5, -0.5]\))를 1절의 네 분해와 나란히 놓아보자. 1절에서는 0/1 XOR에 대해 일부러 서로 다른 분해를 골랐기 때문에, **네 가지 중 어느 것도 fANOVA 분해와 일치하지 않는다:**

| 분해 | \(f_0\) | \(f_1(1)\) (= \(f_2(1)\)) | \(f_{12}\) | fANOVA 조건 충족? |
|---|---|---|---|---|
| ① | 0 | 0 | [0, 1; 1, 0] | ✗ |
| ② | 0.25 | +0.25 | [0.25, 0.75; 0.75, -0.75] | ✗ |
| ③ | -0.75 | -0.25 | [0.25, 1.75; 1.75, 1.25] | ✗ |
| ④ | -0.25 | 0 | [0.25, 1.25; 1.25, 0.25] | ✗ |
| **fANOVA** | **0.5** | **0** | **[-0.5, 0.5; 0.5, -0.5]** | **✓** |

fANOVA 분해만이 아래에서 설명할 조건을 만족하며, **유일하다.** (원논문 Lengerich et al. 2020의 Fig.1은 출력이 \(\pm 0.25\)인 함수를 쓰기 때문에, 그 그림에서는 네 번째 표현 (d)가 곧 fANOVA 정준형이다.)

분해 ①과 fANOVA는 main effect가 둘 다 0이라는 점에서 비슷해 보이지만, intercept가 다르다. ①에서 \(f_0 = 0\)이고 \(f_{12}\)의 평균이 \((0 + 1 + 1 + 0)/4 = 0.5\)인 반면, fANOVA에서는 그 0.5가 \(f_0\)로 옮겨져서 \(f_{12}\)의 평균이 \((-0.5 + 0.5 + 0.5 + (-0.5))/4 = 0\)이 된다. 이것이 아래에서 다룰 Zero Means 성질이다.

## fANOVA 분해가 갖는 세 가지 성질

fANOVA 분해는 다음 세 가지 성질을 갖는다. 이 세 가지는 분해를 **정의**하는 조건이라기보다, 다음 절의 Integrate-to-Zero 조건에서 **따라 나오는 결과**다. 각 성질이 무엇을 의미하는지 XOR 예시로 확인하고, 마지막에 "왜 이 세 가지만으로는 유일성이 보장되지 않는가"를 짚는다.

### Zero Means (평균 0)

$$
\mathbb{E}[f_S(\mathbf{X}_S)] = 0 \quad \forall\, S \neq \emptyset
\tag{2}
$$

intercept(\(f_0\))를 제외한 **모든 component의 기대값이 0**이다. 전체 평균은 \(f_0\) 하나에만 담기고, 나머지 component는 그 평균으로부터의 **편차**만 표현한다. 1절에서 본 분해 ①과 ④의 차이(intercept를 어디에 담을지)를 이 성질이 해결한다.

XOR 예시로 검증:

| component | 기대값 계산 | 결과 | 충족? |
|---|---|---|---|
| \(f_1\) | \((0 + 0) / 2\) | \(0\) | ✓ |
| \(f_2\) | \((0 + 0) / 2\) | \(0\) | ✓ |
| \(f_{12}\) | \((-0.5 + 0.5 + 0.5 + (-0.5)) / 4\) | \(0\) | ✓ |

반면 1절의 분해 ①에서 \(f_{12}\)의 기대값 = \((0 + 1 + 1 + 0)/4 = 0.5 \neq 0\). 전체 평균 0.5가 교호작용에 남아 있으므로, Zero Means를 위반한다.

### Orthogonality (직교성)

$$
\mathbb{E}[f_S(\mathbf{X}_S) \cdot f_V(\mathbf{X}_V)] = 0 \quad \forall\, S \neq V
\tag{3}
$$

서로 다른 component끼리 곱해서 기대값을 구하면 0이다. Zero Means와 함께 보면, 이것은 **서로 다른 component의 공분산이 0**이라는 뜻이다. 즉, 두 component가 **선형적으로 겹치지 않는다**. (공분산이 0이라는 것은 "무상관"이지 "독립"은 아니다 — 하나를 알면 다른 하나에 대해 비선형적인 정보는 있을 수 있다.)

XOR 예시에서 \(f_1 = f_2 = 0\)이므로, \(f_1 \cdot f_{12} = 0\)은 자명하다. 일반적으로는 non-trivial한 성질이며, main effect가 0이 아닌 함수에서 중요해진다.

식 (3)이 **모든** \(S \neq V\) 쌍에 대해 성립하는 것은 변수 독립(product measure)일 때다. 변수가 상관된 분포에서 정의한 일반화 fANOVA(Hooker, 2007)는 \(f_1\)과 \(f_{12}\)처럼 **한쪽이 다른 쪽의 부분집합인 쌍**에 대해서만 직교성을 유지하고, \(f_1\)과 \(f_2\)처럼 겹치지 않는 쌍은 상관될 수 있다([부록 B 2절](../correlation-interpretation/joint-vs-product.md)).

### Variance Decomposition (분산 분해)

$$
\sigma^2(\hat{f}) = \sum_{S \subseteq [p],\, S \neq \emptyset} \sigma^2(f_S)
\tag{4}
$$

총 분산 = 각 component 분산의 합. 식 (2)와 (3)의 직접적 결과다 — 합의 분산을 전개하면 교차항이 모두 공분산이고, 그것이 0이기 때문이다. 실무적으로 중요한 의미가 있다: **각 component가 전체 분산의 몇 %를 차지하는지**를 계산할 수 있게 된다. 예를 들어 "소득의 main effect가 전체 분산의 40%를 설명하고, 소득×DTI 교호작용은 5%에 불과하다"라는 진술이 가능해진다.

XOR 예시:

- 총 분산: \(\sigma^2(Y) = \mathbb{E}[(Y - 0.5)^2] = \frac{(0-0.5)^2 + (1-0.5)^2 + (1-0.5)^2 + (0-0.5)^2}{4} = \frac{0.25 \times 4}{4} = 0.25\)
- \(\sigma^2(f_1) = 0\), \(\sigma^2(f_2) = 0\)
- \(\sigma^2(f_{12}) = \frac{(-0.5)^2 + 0.5^2 + 0.5^2 + (-0.5)^2}{4} = \frac{0.25 \times 4}{4} = 0.25\)
- 합계: \(0 + 0 + 0.25 = 0.25\) ✓

이것은 **XOR의 모든 분산이 교호작용에서 온다**는 것을 의미한다. 변수 하나로는 XOR을 전혀 설명할 수 없으니 직관적으로도 맞다.

!!! warning "분산 분해는 독립 가정에서만 깔끔하다"
    식 (4)는 분산을 계산하는 분포와 분해에 쓴 측도가 모두 product measure일 때 성립한다. 실제 데이터처럼 변수가 상관되어 있으면, 어느 측도로 분해하든 **데이터 분포 위에서** 계산한 분산에는 component 간 교차공분산 항이 남는다. 신용평가 모형에서는 이 교차공분산이 전체 분산의 상당 부분을 차지할 수 있다 — [부록 B 2절](../correlation-interpretation/joint-vs-product.md)에서 수치로 확인한다.

### main effect vs interaction — 비중을 정량화할 수 있다

Variance Decomposition이 실무적으로 중요한 이유는, **main effect와 교호작용의 상대적 비중**을 정량적으로 판단할 수 있기 때문이다. XOR에서는 main이 0%, interaction이 100%였다. 변수 독립 가정이 성립하는 이상적인 상황이라면, 예를 들어 다음과 같은 결과를 얻을 수 있다 (아래 표는 설명을 위한 **가상 수치**다):

| component | \(\sigma^2\) | 비중 |
|---|---|---|
| \(f_{\text{소득}}\) (main) | 0.22 | 22% |
| \(f_{\text{DTI}}\) (main) | 0.15 | 15% |
| \(f_{\text{연체}}\) (main) | 0.35 | 35% |
| 기타 main effects | 0.20 | 20% |
| \(f_{\text{소득,DTI}}\) (interaction) | 0.05 | 5% |
| 기타 interactions | 0.03 | 3% |
| **합계** | **1.00** | **100%** |

이 테이블이 말해주는 것: **main effect가 전체 분산의 92%를 설명하고, 교호작용은 8%에 불과하다.** 이런 결과라면 교호작용은 미미하며, 교호작용 없는 모형(GAM)으로 단순화하는 것을 검토할 근거가 된다. (분산 비중이 작다는 것이 곧 예측 성능 차이가 작다는 뜻은 아니므로, 최종 판단은 KS, AR 비교로 확인한다.)

이것이 전통 ANOVA에서 "SSB / SST = 몇 %"로 요인의 중요성을 판단하는 것과 **같은 발상**이다. fANOVA는 이 발상을 ML 모형에 그대로 가져온 것이다.

SHAP의 `mean(|SHAP|)`로는 이 판단을 하기 어렵다. 변수별 SHAP 값에는 주효과와 교호작용의 몫이 함께 들어 있기 때문이다([4절](shap-vs-fanova.md) 참조). SHAP interaction value(Lundberg et al., 2020)를 쓰면 쌍별 교호작용 기여를 따로 볼 수는 있지만, 이것은 개별 예측에 대한 분배값이지 "전체 분산의 몇 %"라는 분해가 아니다. fANOVA의 Variance Decomposition은 "우리 모형에서 교호작용이 실제로 중요한가?"라는 질문에 **분산 비율이라는 숫자로** 답한다 — 이것이 fANOVA가 "ANOVA"라는 이름을 달고 있는 이유이기도 하다.

### 세 가지 성질만으로는 유일성이 보장되지 않는다

Zero Means와 Orthogonality는 "서로 다른 component끼리" 겹치지 않으면 된다는 조건이다. 그런데 이것만으로는 효과를 **통째로** 다른 component로 옮기는 것을 막지 못한다. 간단한 반례를 보자.

\(X_1, X_2\)가 서로 독립이고 각각 \(\pm 1\)을 같은 확률로 갖는다고 하자. 함수 \(\hat{f}(x_1, x_2) = x_1\)에 대해 다음 두 분해를 생각한다.

| | \(f_0\) | \(f_1\) | \(f_2\) | \(f_{12}\) |
|---|---|---|---|---|
| 분해 (가) | 0 | \(x_1\) | 0 | 0 |
| 분해 (나) | 0 | 0 | 0 | \(x_1\) |

두 분해 모두 합이 \(x_1\)이고, 모든 component의 평균이 0이며(식 2), 0이 아닌 component가 하나뿐이므로 서로 다른 component의 곱의 기대값도 모두 0이다(식 3). 분산 분해(식 4)도 성립한다. 그러나 분해 (나)는 \(X_1\)만으로 설명되는 효과를 교호작용이라고 부르고 있다. 이 분해를 걸러내려면 "\(f_{12}\)는 \(X_1\)만의 함수와도, \(X_2\)만의 함수와도 겹치지 않아야 한다"는 더 강한 조건이 필요하다. 그것이 다음 절의 Integrate-to-Zero다.

## 핵심: Integrate-to-Zero — 유일성을 보장하는 조건

fANOVA 분해를 유일하게 결정하는 조건은 **Integrate-to-Zero**다. 3절의 Purification 알고리즘이 바로 이 조건을 만족시키는 방향으로 작동하므로, 그 의미를 정확히 이해할 필요가 있다. 독립 가정(product measure)에서는 다음과 같이 쓴다:

$$
\forall\, S \subseteq [p], \quad \forall\, i \in S: \quad \int f_S(\mathbf{x}_S)\, d\mathbb{P}(x_i) = 0
\tag{5}
$$

즉, component \(f_S\)를 그 안의 **어느 한 변수 \(x_i\) 방향으로 적분해도 0**이 되어야 한다. 이것은 \(f_S\)가 \(S\)보다 작은 변수 집합의 **어떤 함수와도** 직교한다는 조건(위계적 직교성)과 동치다 (Lengerich et al., 2020, 식 5b–5c; Hooker, 2007). 식 (5)를 만족하는 분해는 식 (2)~(4)의 세 성질을 모두 갖추며, 주어진 측도에서 **유일하다.**

수식이 추상적이므로, 풀어서 읽자. \(S = \{1, 2\}\)(2차 교호작용)이고 \(i = 1\)인 경우:

> \(f_{12}\)에서 \(X_2\)의 값을 고정한 채 \(X_1\) 방향으로 (가중)평균을 내면, 결과가 0이어야 한다.

\(i = 2\)이면 반대로 "\(X_1\)을 고정하고 \(X_2\) 방향으로 평균"이 0이어야 한다. 두 조건을 합치면: **교호작용 테이블의 모든 행과 모든 열의 가중평균이 0이어야 한다.** 만약 \(X_1 = a\)인 행의 평균이 0이 아니라면, 그 평균값은 \(X_1\)의 값에만 의존하는 효과 — 즉 \(X_1\)의 main effect — 이지 교호작용이 아니다. 교호작용에 main effect가 **누출**되어 있다는 뜻이다.

이것이 실질적으로 검사하는 것: **\(f_{12}\)에 \(f_1\)이나 \(f_2\)에 담겨야 할 효과가 남아 있지 않은가?** 앞의 반례에서 분해 (나)의 \(f_{12} = x_1\)은 \(X_1 = 1\)인 행의 평균이 1, \(X_1 = -1\)인 행의 평균이 -1이므로 이 조건을 위반한다.

변수가 상관된 분포(joint measure)에서는 식 (5)의 적분이 결합분포에 대한 조건부 평균 \(\mathbb{E}[f_S(\mathbf{X}_S) \mid \mathbf{X}_{S \setminus i}] = 0\) 형태로 바뀐다. 이 일반화는 [부록 B 2절](../correlation-interpretation/joint-vs-product.md)에서 다룬다.

### XOR 예시로 검증

fANOVA의 \(f_{12} = [-0.5, 0.5;\; 0.5, -0.5]\):

- \(X_1\)을 고정하고 \(X_2\)에 대해 평균 (식 5에서 \(i = 2\)):
    - \(X_1=0\): \((-0.5 + 0.5)/2 = 0\) ✓
    - \(X_1=1\): \((0.5 + (-0.5))/2 = 0\) ✓
- \(X_2\)를 고정하고 \(X_1\)에 대해 평균 (식 5에서 \(i = 1\)):
    - \(X_2=0\): \((-0.5 + 0.5)/2 = 0\) ✓
    - \(X_2=1\): \((0.5 + (-0.5))/2 = 0\) ✓

**모든 행/열 평균이 0이다.** \(f_{12}\)에는 \(X_1\)만으로 설명 가능한 패턴도, \(X_2\)만으로 설명 가능한 패턴도 남아 있지 않다. 이것이 **순수한 교호작용**(pure interaction) — 두 변수가 **동시에** 특정 조합일 때만 나타나는, 더 적은 수의 변수로는 설명할 수 없는 효과다. 또한 \(f_1, f_2\)도 각자의 변수 방향으로 평균하면 0이므로(식 5에서 \(S\)가 한 변수인 경우), Zero Means가 함께 성립한다.

### 1절의 분해 ①이 왜 실패하는가

비교: 분해 ①의 \(f_{12} = [0, 1;\; 1, 0]\):

- \(X_2=0\) 고정, \(X_1\) 방향 평균: \((0 + 1)/2 = 0.5 \neq 0\) ✗

이 0.5는 "\(X_2=0\)일 때의 평균 출력"이다. 이것은 \(X_2\)의 값에만 의존하는 효과(이 경우에는 \(X_2\)의 값과 무관하게 0.5이므로 intercept에 해당하는 값)다. 이것이 \(f_{12}\) 안에 남아 있다는 것은 교호작용 테이블에 하위 component의 몫이 **누출**되어 있다는 뜻이다.

fANOVA는 이런 누출을 허용하지 않는다. **교호작용에는 교호작용만, main effect에는 main effect만** — 이 원칙을 수학적으로 강제하는 것이 Integrate-to-Zero 조건이다.

---

정리하면, Integrate-to-Zero(식 5)를 만족하는 분해는 주어진 측도 위에서 **유일(unique)**하고, Zero Means·Orthogonality·Variance Decomposition은 그 결과로 따라온다. 1절의 곱셈 모형 관점에서 보면, fANOVA는 교호작용 항의 분산이 최소가 되도록 \(\alpha, \beta\)를 고르는 규칙이기도 하다(Lengerich et al., 2020, 1.2절). 비로소 "이 변수의 효과가 양이다/음이다"를 하나의 기준 위에서 말할 수 있게 된다. 단, 그 기준은 **어떤 측도를 쓰느냐**에 따라 달라진다는 점을 잊지 말아야 한다.

그런데 XGBoost 같은 트리 기반 모형은 학습 과정에서 이 조건을 고려하지 않는다. 학습된 shape function이 이미 뒤섞여 있을 때, 이를 **사후적으로** 바로잡는 알고리즘이 필요하다. 다음 절에서 그 알고리즘(Purification)이 어떻게 작동하는지, 구체적인 숫자 예시로 확인한다. → [3절. Purification — 트리 모형의 사후 정제](purification.md)
